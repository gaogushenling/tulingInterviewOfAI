## <font style="color:rgb(31, 35, 40);">模型发布</font>
<font style="color:rgb(31, 35, 40);">将您的模型发布到社区，在Hugging Face，我们相信公开分享知识和资源，能实现人工智能的普及化，让每个人都能受益。我们鼓励您将您的模型与社区分享，以帮助他人节省时间和精力。</font>

<font style="color:rgb(31, 35, 40);">在本教程中，您将学习两种在</font>[Model Hub](https://huggingface.co/models)<font style="color:rgb(31, 35, 40);">上共享训练好的或微调的模型的方法：</font>

+ <font style="color:rgb(31, 35, 40);">通过编程将文件推送到Hub。</font>
+ <font style="color:rgb(31, 35, 40);">使用Web界面将文件拖放到Hub。</font>

<font style="color:rgb(31, 35, 40);">要与社区共享模型，您需要在</font>[huggingface.co](https://huggingface.co/join)<font style="color:rgb(31, 35, 40);">上拥有一个帐户。您还可以加入现有的组织或创建一个新的组织。</font>

## <font style="color:rgb(31, 35, 40);">仓库功能</font>
<font style="color:rgb(31, 35, 40);">Model Hub上的每个仓库都像是一个典型的GitHub仓库。我们的仓库提供版本控制、提交历史记录以及可视化差异的能力。</font>

<font style="color:rgb(31, 35, 40);">Model Hub的内置版本控制基于git和</font>[git-lfs](https://git-lfs.github.com/)<font style="color:rgb(31, 35, 40);">。换句话说，您可以将一个模型视为一个仓库，从而实现更好的访问控制和可扩展性。版本控制允许使用</font>_<font style="color:rgb(31, 35, 40);">修订</font>_<font style="color:rgb(31, 35, 40);">方法来固定特定版本的模型，可以使用提交哈希值、标签或分支来标记。</font>

<font style="color:rgb(31, 35, 40);">因此，您可以通过</font>`<font style="color:rgb(31, 35, 40);">revision</font>`<font style="color:rgb(31, 35, 40);">参数加载特定的模型版本：</font>

```plain
>>> model = AutoModel.from_pretrained(
...     "julien-c/EsperBERTo-small", revision="4c77982"  # tag name, or branch name, or commit hash
... )
```

<font style="color:rgb(31, 35, 40);">文件也可以轻松地在仓库中编辑，您可以查看提交历史记录以及差异：</font><font style="color:rgb(31, 35, 40);"> </font>![](https://camo.githubusercontent.com/83ce40033e1e4571338b89d71330bb8d8a30034a331601026a3214429e4ec4b8/68747470733a2f2f68756767696e67666163652e636f2f64617461736574732f68756767696e67666163652f646f63756d656e746174696f6e2d696d616765732f7265736f6c76652f6d61696e2f7669735f646966662e706e67)

## <font style="color:rgb(31, 35, 40);">设置</font>
<font style="color:rgb(31, 35, 40);">在将模型共享到Hub之前，您需要拥有Hugging Face的凭证。如果您有访问终端的权限，请在安装</font><font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Transformers的虚拟环境中运行以下命令。这将在您的Hugging Face缓存文件夹（默认为</font>`<font style="color:rgb(31, 35, 40);">~/.cache/</font>`<font style="color:rgb(31, 35, 40);">）中存储您的</font>`<font style="color:rgb(31, 35, 40);">access token</font>`<font style="color:rgb(31, 35, 40);">：</font>

<font style="color:rgb(31, 35, 40);">huggingface-cli login</font>

<font style="color:rgb(31, 35, 40);">如果您正在使用像Jupyter或Colaboratory这样的</font>`<font style="color:rgb(31, 35, 40);">notebook</font>`<font style="color:rgb(31, 35, 40);">，请确保您已安装了</font>[huggingface_hub](https://huggingface.co/docs/hub/adding-a-library)<font style="color:rgb(31, 35, 40);">库。该库允许您以编程方式与Hub进行交互。</font>

<font style="color:rgb(31, 35, 40);">pip install huggingface_hub</font>

<font style="color:rgb(31, 35, 40);">然后使用</font>`<font style="color:rgb(31, 35, 40);">notebook_login</font>`<font style="color:rgb(31, 35, 40);">登录到Hub，并按照</font>[这里](https://huggingface.co/settings/token)<font style="color:rgb(31, 35, 40);">的链接生成一个token进行登录：</font>

```plain
>>> from huggingface_hub import notebook_login

>>> notebook_login()
```

## <font style="color:rgb(31, 35, 40);">转换模型适用于所有框架</font>
<font style="color:rgb(31, 35, 40);">为确保您的模型可以被使用不同框架的人使用，我们建议您将PyTorch和TensorFlow</font><font style="color:rgb(31, 35, 40);"> </font>`<font style="color:rgb(31, 35, 40);">checkpoints</font>`<font style="color:rgb(31, 35, 40);">都转换并上传。如果您跳过此步骤，用户仍然可以从其他框架加载您的模型，但速度会变慢，因为</font><font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Transformers需要实时转换</font>`<font style="color:rgb(31, 35, 40);">checkpoints</font>`<font style="color:rgb(31, 35, 40);">。</font>

<font style="color:rgb(31, 35, 40);">为另一个框架转换</font>`<font style="color:rgb(31, 35, 40);">checkpoints</font>`<font style="color:rgb(31, 35, 40);">很容易。确保您已安装PyTorch和TensorFlow（请参阅</font>[此处](https://github.com/huggingface/transformers/blob/main/docs/source/zh/installation)<font style="color:rgb(31, 35, 40);">的安装说明），然后在其他框架中找到适合您任务的特定模型。</font>

<font style="color:rgb(31, 35, 40);">指定</font>`<font style="color:rgb(31, 35, 40);">from_tf=True</font>`<font style="color:rgb(31, 35, 40);">将checkpoint从TensorFlow转换为PyTorch。</font>

```plain
>>> pt_model = DistilBertForSequenceClassification.from_pretrained("path/to/awesome-name-you-picked", from_tf=True)
>>> pt_model.save_pretrained("path/to/awesome-name-you-picked")
```

<font style="color:rgb(31, 35, 40);">指定</font>`<font style="color:rgb(31, 35, 40);">from_pt=True</font>`<font style="color:rgb(31, 35, 40);">将checkpoint从PyTorch转换为TensorFlow。</font>

<font style="color:rgb(31, 35, 40);">>>> tf_model = TFDistilBertForSequenceClassification.from_pretrained("path/to/awesome-name-you-picked", from_pt=True)</font>

<font style="color:rgb(31, 35, 40);">然后，您可以使用新的checkpoint保存您的新TensorFlow模型：</font>

<font style="color:rgb(31, 35, 40);">>>> tf_model.save_pretrained("path/to/awesome-name-you-picked")</font>

<font style="color:rgb(31, 35, 40);">如果模型在Flax中可用，您还可以将PyTorch checkpoint转换为Flax：</font>

```plain
>>> flax_model = FlaxDistilBertForSequenceClassification.from_pretrained(
...     "path/to/awesome-name-you-picked", from_pt=True
... )
```

## <font style="color:rgb(31, 35, 40);">在训练过程中推送模型</font>
<font style="color:rgb(31, 35, 40);">将模型分享到Hub就像添加一个额外的参数或回调函数一样简单。请记住，在</font>[微调教程](https://github.com/huggingface/transformers/blob/main/docs/source/zh/training)<font style="color:rgb(31, 35, 40);">中，</font>`<font style="color:rgb(31, 35, 40);">TrainingArguments</font>`<font style="color:rgb(31, 35, 40);">类是您指定超参数和附加训练选项的地方。其中一项训练选项包括直接将模型推送到Hub的能力。在您的</font>`<font style="color:rgb(31, 35, 40);">TrainingArguments</font>`<font style="color:rgb(31, 35, 40);">中设置</font>`<font style="color:rgb(31, 35, 40);">push_to_hub=True</font>`<font style="color:rgb(31, 35, 40);">：</font>

<font style="color:rgb(31, 35, 40);">>>> training_args = TrainingArguments(output_dir="my-awesome-model", push_to_hub=True)</font>

<font style="color:rgb(31, 35, 40);">像往常一样将您的训练参数传递给[</font>`<font style="color:rgb(31, 35, 40);">Trainer</font>`<font style="color:rgb(31, 35, 40);">]：</font>

```plain
>>> trainer = Trainer(
...     model=model,
...     args=training_args,
...     train_dataset=small_train_dataset,
...     eval_dataset=small_eval_dataset,
...     compute_metrics=compute_metrics,
... )
```

<font style="color:rgb(31, 35, 40);">在您微调完模型后，在[</font>`<font style="color:rgb(31, 35, 40);">Trainer</font>`<font style="color:rgb(31, 35, 40);">]上调用[</font>`<font style="color:rgb(31, 35, 40);">~transformers.Trainer.push_to_hub</font>`<font style="color:rgb(31, 35, 40);">]将训练好的模型推送到Hub。</font><font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Transformers甚至会自动将训练超参数、训练结果和框架版本添加到你的模型卡片中！</font>

<font style="color:rgb(31, 35, 40);">>>> trainer.push_to_hub()</font>

<font style="color:rgb(31, 35, 40);">使用[</font>`<font style="color:rgb(31, 35, 40);">PushToHubCallback</font>`<font style="color:rgb(31, 35, 40);">]将模型分享到Hub。在[</font>`<font style="color:rgb(31, 35, 40);">PushToHubCallback</font>`<font style="color:rgb(31, 35, 40);">]函数中，添加以下内容：</font>

+ <font style="color:rgb(31, 35, 40);">一个用于存储模型的输出目录。</font>
+ <font style="color:rgb(31, 35, 40);">一个tokenizer。</font>
+ `<font style="color:rgb(31, 35, 40);">hub_model_id</font>`<font style="color:rgb(31, 35, 40);">，即您的Hub用户名和模型名称。</font>

```plain
>>> from transformers import PushToHubCallback

>>> push_to_hub_callback = PushToHubCallback(
...     output_dir="./your_model_save_path", tokenizer=tokenizer, hub_model_id="your-username/my-awesome-model"
... )
```

<font style="color:rgb(31, 35, 40);">将回调函数添加到</font><font style="color:rgb(31, 35, 40);"> </font>[fit](https://keras.io/api/models/model_training_apis/)<font style="color:rgb(31, 35, 40);">中，然后</font><font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Transformers 会将训练好的模型推送到 Hub：</font>

<font style="color:rgb(31, 35, 40);">>>> model.fit(tf_train_dataset, validation_data=tf_validation_dataset, epochs=3, callbacks=push_to_hub_callback)</font>

## <font style="color:rgb(31, 35, 40);">使用</font>`<font style="color:rgb(31, 35, 40);">push_to_hub</font>`<font style="color:rgb(31, 35, 40);">功能</font>
<font style="color:rgb(31, 35, 40);">您可以直接在您的模型上调用</font>`<font style="color:rgb(31, 35, 40);">push_to_hub</font>`<font style="color:rgb(31, 35, 40);">来将其上传到Hub。</font>

<font style="color:rgb(31, 35, 40);">在</font>`<font style="color:rgb(31, 35, 40);">push_to_hub</font>`<font style="color:rgb(31, 35, 40);">中指定你的模型名称：</font>

<font style="color:rgb(31, 35, 40);">>>> pt_model.push_to_hub("my-awesome-model")</font>

<font style="color:rgb(31, 35, 40);">这会在您的用户名下创建一个名为</font>`<font style="color:rgb(31, 35, 40);">my-awesome-model</font>`<font style="color:rgb(31, 35, 40);">的仓库。用户现在可以使用</font>`<font style="color:rgb(31, 35, 40);">from_pretrained</font>`<font style="color:rgb(31, 35, 40);">函数加载您的模型：</font>

```plain
>>> from transformers import AutoModel

>>> model = AutoModel.from_pretrained("your_username/my-awesome-model")
```

<font style="color:rgb(31, 35, 40);">如果您属于一个组织，并希望将您的模型推送到组织名称下，只需将其添加到</font>`<font style="color:rgb(31, 35, 40);">repo_id</font>`<font style="color:rgb(31, 35, 40);">中：</font>

<font style="color:rgb(31, 35, 40);">>>> pt_model.push_to_hub("my-awesome-org/my-awesome-model")</font>

`<font style="color:rgb(31, 35, 40);">push_to_hub</font>`<font style="color:rgb(31, 35, 40);">函数还可以用于向模型仓库添加其他文件。例如，向模型仓库中添加一个</font>`<font style="color:rgb(31, 35, 40);">tokenizer</font>`<font style="color:rgb(31, 35, 40);">：</font>

<font style="color:rgb(31, 35, 40);">>>> tokenizer.push_to_hub("my-awesome-model")</font>

<font style="color:rgb(31, 35, 40);">或者，您可能希望将您的微调后的PyTorch模型的TensorFlow版本添加进去：</font>

<font style="color:rgb(31, 35, 40);">>>> tf_model.push_to_hub("my-awesome-model")</font>

<font style="color:rgb(31, 35, 40);">现在，当您导航到您的Hugging Face个人资料时，您应该看到您新创建的模型仓库。点击</font>**<font style="color:rgb(31, 35, 40);">文件</font>**<font style="color:rgb(31, 35, 40);">选项卡将显示您已上传到仓库的所有文件。</font>

<font style="color:rgb(31, 35, 40);">有关如何创建和上传文件到仓库的更多详细信息，请参考Hub文档</font>[这里](https://huggingface.co/docs/hub/how-to-upstream)<font style="color:rgb(31, 35, 40);">。</font>
