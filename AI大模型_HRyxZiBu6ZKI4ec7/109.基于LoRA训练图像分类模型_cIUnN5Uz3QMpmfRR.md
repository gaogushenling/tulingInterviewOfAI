## <font style="color:#000000;">前言</font>

<font style="color:rgb(74, 85, 101);">一种有效训练大型模型的常用方法是插入（通常在注意力模块中）较小的可训练矩阵，这些矩阵是在微调期间要学习的增量权重矩阵的低秩分解。预训练模型的原始权重矩阵被冻结，只有较小的矩阵在训练期间更新。这减少了可训练参数的数量，从而减少了内存使用和训练时间，对于大型模型来说，这可能非常昂贵。</font>

<font style="color:rgb(74, 85, 101);">有几种不同的方法可以将权重矩阵表示为低秩分解，但</font>[低秩自适应 (LoRA)](https://hugging-face.cn/docs/peft/conceptual_guides/adapter#low-rank-adaptation-lora)<font style="color:rgb(74, 85, 101);">是最常用的方法。PEFT 库支持其他几种 LoRA 变体，例如</font>[低秩哈达玛积 (LoHa)](https://hugging-face.cn/docs/peft/conceptual_guides/adapter#low-rank-hadamard-product-loha)<font style="color:rgb(74, 85, 101);">、</font>[低秩克罗内克积 (LoKr)](https://hugging-face.cn/docs/peft/conceptual_guides/adapter#low-rank-kronecker-product-lokr)<font style="color:rgb(74, 85, 101);">和</font>[自适应低秩自适应 (AdaLoRA)](https://hugging-face.cn/docs/peft/conceptual_guides/adapter#adaptive-low-rank-adaptation-adalora)<font style="color:rgb(74, 85, 101);">。您可以在</font>[适配器](https://hugging-face.cn/docs/peft/conceptual_guides/adapter)<font style="color:rgb(74, 85, 101);">指南中了解有关这些方法在概念上如何工作的更多信息。如果您有兴趣将这些方法应用于其他任务和用例，例如语义分割、token 分类，请查看我们的</font>[notebook 合集](https://hugging-face.cn/collections/PEFT/notebooks-6573b28b33e5a4bf5b157fc1)<font style="color:rgb(74, 85, 101);">！</font>

<font style="color:rgb(74, 85, 101);">此外，PEFT 支持</font><font style="color:rgb(74, 85, 101);"> </font>[X-LoRA](https://hugging-face.cn/docs/peft/conceptual_guides/adapter#mixture-of-lora-experts-x-lora)<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">LoRA 专家混合方法。</font>

<font style="color:rgb(74, 85, 101);">本指南将向您展示如何使用低秩分解方法快速训练图像分类模型，以识别图像中显示的食物类别。</font>

## 数据集

<font style="color:rgb(74, 85, 101);">在本指南中，您将使用包含 101 个食物类别的图像的</font><font style="color:rgb(74, 85, 101);"> </font>[Food-101](https://hugging-face.cn/datasets/food101)<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">数据集（查看</font>[数据集查看器](https://hugging-face.cn/datasets/food101/viewer/default/train)<font style="color:rgb(74, 85, 101);">，以更好地了解数据集的外观）。</font>

<font style="color:rgb(74, 85, 101);">使用</font><font style="color:rgb(74, 85, 101);"> </font>[load_dataset](https://hugging-face.cn/docs/datasets/v3.4.1/en/package_reference/loading_methods#datasets.load_dataset)<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">函数加载数据集。</font>

```plain
from datasets import load_dataset

ds = load_dataset("food101")
```

<font style="color:rgb(74, 85, 101);">每个食物类别都用一个整数标记，为了更容易理解这些整数代表什么，您将创建一个</font><font style="color:rgb(74, 85, 101);"> </font>`label2id`<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">和</font><font style="color:rgb(74, 85, 101);"> </font>`id2label`<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">字典，将整数映射到其类别标签。</font>

```plain
labels = ds["train"].features["label"].names
label2id, id2label = dict(), dict()
for i, label in enumerate(labels):
    label2id[label] = i
    id2label[i] = label

id2label[2]
"baklava"
```

<font style="color:rgb(74, 85, 101);">加载图像处理器以正确调整大小并标准化训练和评估图像的像素值。</font>

```plain
from transformers import AutoImageProcessor

image_processor = AutoImageProcessor.from_pretrained("google/vit-base-patch16-224-in21k")
```

<font style="color:rgb(74, 85, 101);">您还可以使用图像处理器来准备一些用于数据增强和像素缩放的转换函数。</font>

```plain
from torchvision.transforms import (
    CenterCrop,
    Compose,
    Normalize,
    RandomHorizontalFlip,
    RandomResizedCrop,
    Resize,
    ToTensor,
)

normalize = Normalize(mean=image_processor.image_mean, std=image_processor.image_std)
train_transforms = Compose(
    [
        RandomResizedCrop(image_processor.size["height"]),
        RandomHorizontalFlip(),
        ToTensor(),
        normalize,
    ]
)

val_transforms = Compose(
    [
        Resize(image_processor.size["height"]),
        CenterCrop(image_processor.size["height"]),
        ToTensor(),
        normalize,
    ]
)

def preprocess_train(example_batch):
    example_batch["pixel_values"] = [train_transforms(image.convert("RGB")) for image in example_batch["image"]]
    return example_batch

def preprocess_val(example_batch):
    example_batch["pixel_values"] = [val_transforms(image.convert("RGB")) for image in example_batch["image"]]
    return example_batch
```

<font style="color:rgb(74, 85, 101);">定义训练和验证数据集，并使用</font><font style="color:rgb(74, 85, 101);"> </font>[set_transform](https://hugging-face.cn/docs/datasets/v3.4.1/en/package_reference/main_classes#datasets.Dataset.set_transform)<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">函数即时应用转换。</font>

```plain
train_ds = ds["train"]
val_ds = ds["validation"]

train_ds.set_transform(preprocess_train)
val_ds.set_transform(preprocess_val)
```

<font style="color:rgb(74, 85, 101);">最后，您需要一个数据整理器来创建一批训练和评估数据，并将标签转换为</font><font style="color:rgb(74, 85, 101);"> </font>`torch.tensor`<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">对象。</font>

```plain
import torch

def collate_fn(examples):
    pixel_values = torch.stack([example["pixel_values"] for example in examples])
    labels = torch.tensor([example["label"] for example in examples])
    return {"pixel_values": pixel_values, "labels": labels}
```

## 模型

<font style="color:rgb(74, 85, 101);">现在让我们加载一个预训练模型用作基础模型。本指南使用</font><font style="color:rgb(74, 85, 101);"> </font>[google/vit-base-patch16-224-in21k](https://hugging-face.cn/google/vit-base-patch16-224-in21k)<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">模型，但您可以使用任何您想要的图像分类模型。将</font><font style="color:rgb(74, 85, 101);"> </font>`label2id`<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">和</font><font style="color:rgb(74, 85, 101);"> </font>`id2label`<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">字典传递给模型，以便模型知道如何将整数标签映射到其类别标签，如果您要微调已经微调过的检查点，您可以选择传递</font><font style="color:rgb(74, 85, 101);"> </font>`ignore_mismatched_sizes=True`<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">参数。</font>

```plain
from transformers import AutoModelForImageClassification, TrainingArguments, Trainer

model = AutoModelForImageClassification.from_pretrained(
    "google/vit-base-patch16-224-in21k",
    label2id=label2id,
    id2label=id2label,
    ignore_mismatched_sizes=True,
)
```

### PEFT 配置和模型

<font style="color:rgb(74, 85, 101);">每个 PEFT 方法都需要一个配置，其中包含指定应如何应用 PEFT 方法的所有参数。配置设置完成后，将其与基础模型一起传递给</font><font style="color:rgb(74, 85, 101);"> </font>[get_peft_model()](https://hugging-face.cn/docs/peft/v0.15.0/en/package_reference/peft_model#peft.get_peft_model)<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">函数，以创建一个可训练的</font><font style="color:rgb(74, 85, 101);"> </font>[PeftModel](https://hugging-face.cn/docs/peft/v0.15.0/en/package_reference/peft_model#peft.PeftModel)<font style="color:rgb(74, 85, 101);">。</font>

调用 [print_trainable_parameters()](https://hugging-face.cn/docs/peft/v0.15.0/en/package_reference/peft_model#peft.PeftModel.print_trainable_parameters) 方法，比较 [PeftModel](https://hugging-face.cn/docs/peft/v0.15.0/en/package_reference/peft_model#peft.PeftModel) 的参数数量与基础模型中的参数数量！

[LoRA](https://hugging-face.cn/docs/peft/conceptual_guides/adapter#low-rank-adaptation-lora)<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">将权重更新矩阵分解为*两个*较小的矩阵。这些低秩矩阵的大小由其*秩*或</font><font style="color:rgb(74, 85, 101);"> </font>`r`<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">决定。秩越高意味着模型有更多的参数要训练，但也意味着模型具有更强的学习能力。您还需要指定</font><font style="color:rgb(74, 85, 101);"> </font>`target_modules`<font style="color:rgb(74, 85, 101);">，它确定较小矩阵的插入位置。在本指南中，您将以注意力模块的*query*和*value*矩阵为目标。其他要设置的重要参数包括</font><font style="color:rgb(74, 85, 101);"> </font>`lora_alpha`<font style="color:rgb(74, 85, 101);">（缩放因子）、</font>`bias`<font style="color:rgb(74, 85, 101);">（</font>`none`<font style="color:rgb(74, 85, 101);">、</font>`all`<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">还是仅训练 LoRA 偏差参数），以及</font><font style="color:rgb(74, 85, 101);"> </font>`modules_to_save`<font style="color:rgb(74, 85, 101);">（除了要训练和保存的 LoRA 层之外的模块）。所有这些参数以及更多参数都可以在</font><font style="color:rgb(74, 85, 101);"> </font>[LoraConfig](https://hugging-face.cn/docs/peft/v0.15.0/en/package_reference/lora#peft.LoraConfig)<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">中找到。</font>

```plain
from peft import LoraConfig, get_peft_model

config = LoraConfig(
    r=16,
    lora_alpha=16,
    target_modules=["query", "value"],
    lora_dropout=0.1,
    bias="none",
    modules_to_save=["classifier"],
)
model = get_peft_model(model, config)
model.print_trainable_parameters()
"trainable params: 667,493 || all params: 86,543,818 || trainable%: 0.7712775047664294"
```

### 训练

<font style="color:rgb(74, 85, 101);">对于训练，让我们使用 Transformers 中的</font><font style="color:rgb(74, 85, 101);"> </font>[Trainer](https://hugging-face.cn/docs/transformers/v4.49.0/en/main_classes/trainer#transformers.Trainer)<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">类。</font>`Trainer`<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">包含一个 PyTorch 训练循环，当您准备好后，调用</font><font style="color:rgb(74, 85, 101);"> </font>[train](https://hugging-face.cn/docs/transformers/v4.49.0/en/main_classes/trainer#transformers.Trainer.train)<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">开始训练。要自定义训练运行，请在</font><font style="color:rgb(74, 85, 101);"> </font>[TrainingArguments](https://hugging-face.cn/docs/transformers/v4.49.0/en/main_classes/trainer#transformers.TrainingArguments)<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">类中配置训练超参数。使用类似 LoRA 的方法，您可以负担得起使用更高的批量大小和学习率。</font>

AdaLoRA 有一个 [update_and_allocate()](https://hugging-face.cn/docs/peft/v0.15.0/en/package_reference/adalora#peft.AdaLoraModel.update_and_allocate) 方法，应在每个训练步骤中调用该方法以更新参数预算和掩码，否则不会执行自适应步骤。这需要编写自定义训练循环或子类化 [Trainer](https://hugging-face.cn/docs/transformers/v4.49.0/en/main_classes/trainer#transformers.Trainer) 以合并此方法。例如，请查看这个 [自定义训练循环](https://github.com/huggingface/peft/blob/912ad41e96e03652cabf47522cd876076f7a0c4f/examples/conditional_generation/peft_adalora_seq2seq.py#L120)。

```plain
from transformers import TrainingArguments, Trainer

account = "stevhliu"
peft_model_id = f"{account}/google/vit-base-patch16-224-in21k-lora"
batch_size = 128

args = TrainingArguments(
    peft_model_id,
    remove_unused_columns=False,
    eval_strategy="epoch",
    save_strategy="epoch",
    learning_rate=5e-3,
    per_device_train_batch_size=batch_size,
    gradient_accumulation_steps=4,
    per_device_eval_batch_size=batch_size,
    fp16=True,
    num_train_epochs=5,
    logging_steps=10,
    load_best_model_at_end=True,
    label_names=["labels"],
)
```

<font style="color:rgb(74, 85, 101);">使用</font><font style="color:rgb(74, 85, 101);"> </font>[train](https://hugging-face.cn/docs/transformers/v4.49.0/en/main_classes/trainer#transformers.Trainer.train)<font style="color:rgb(74, 85, 101);"> </font><font style="color:rgb(74, 85, 101);">开始训练。</font>

```plain
trainer = Trainer(
    model,
    args,
    train_dataset=train_ds,
    eval_dataset=val_ds,
    tokenizer=image_processor,
    data_collator=collate_fn,
)
trainer.train()
```
