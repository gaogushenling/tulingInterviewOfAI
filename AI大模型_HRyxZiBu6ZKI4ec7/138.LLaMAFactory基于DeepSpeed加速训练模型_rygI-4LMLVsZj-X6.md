* <font style="color:rgb(0, 0, 0);">加速算子：FlashAttention-2 和 Unsloth。</font>

## <font style="color:rgb(51, 51, 51);">微调的过程</font>

<font style="color:rgb(51, 51, 51);">模型微调通过在特定任务的数据集上继续训练预训练模型来进行，使得模型能够学习到与任务相关的特定特征和知识。这个过程通常涉及到模型权重的微幅调整，而不是从头开始训练一个全新的模型。</font>

<font style="color:rgb(51, 51, 51);">微调过程主要包括以下几个步骤： </font>

1. <font style="color:rgb(51, 51, 51);">数据准备：收集和准备特定任务的数据集。 </font>
2. <font style="color:rgb(51, 51, 51);">模型选择：选择一个预训练模型作为基础模型。 </font>
3. <font style="color:rgb(51, 51, 51);">迁移学习：在新数据集上继续训练模型，同时保留预训练模型的知识。 </font>
4. <font style="color:rgb(51, 51, 51);">参数调整：根据需要调整模型的参数，如学习率、批大小等。 </font>
5. <font style="color:rgb(51, 51, 51);">模型评估：在验证集上评估模型的性能，并根据反馈进行调整。</font>

## <font style="color:rgb(51, 51, 51);">微调的优势</font>

<font style="color:rgb(51, 51, 51);">微调技术带来了多方面的优势：</font><font style="color:rgb(51, 51, 51);">资源效率：相比于从头开始训练模型，微调可以显著减少所需的数据量和计算资源。</font><font style="color:rgb(51, 51, 51);">快速部署：微调可以快速适应新任务，加速模型的部署过程。</font><font style="color:rgb(51, 51, 51);">性能提升：针对特定任务的微调可以提高模型的准确性和鲁棒性。</font><font style="color:rgb(51, 51, 51);">领域适应性：微调可以帮助模型更好地理解和适应特定领域的语言特点。</font>

<font style="color:rgb(51, 51, 51);">通过微调，可以使得预训练模型在这些任务上取得更好的性能，更好地满足实际应用的需求。</font>

# <font style="color:rgb(0, 0, 0);">DeepSpeed分布式训练</font>

<font style="color:rgb(0, 0, 0);">LLaMA-Factory 支持单机多卡和多机多卡分布式训练。同时也支持</font><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">DDP</font><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">,</font><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">DeepSpeed</font><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">和 FSDP 三种分布式引擎。</font>

[DDP](https://pytorch.org/docs/stable/notes/ddp.html)<font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">(DistributedDataParallel) 通过实现模型并行和数据并行实现训练加速。 使用 DDP 的程序需要生成多个进程并且为每个进程创建一个 DDP 实例，他们之间通过</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">torch.distributed</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">库同步。</font>

[DeepSpeed](https://www.microsoft.com/en-us/research/blog/deepspeed-extreme-scale-model-training-for-everyone/)<font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">是微软开发的分布式训练引擎，并提供ZeRO（Zero Redundancy Optimizer）、offload、Sparse Attention、1 bit Adam、流水线并行等优化技术。 您可以根据任务需求与设备选择使用。</font>

[FSDP](https://pytorch.org/tutorials/intermediate/FSDP_tutorial.html)<font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">通过全切片数据并行技术（Fully Sharded Data Parallel）来处理更多更大的模型。在 DDP 中，每张 GPU 都各自保留了一份完整的模型参数和优化器参数。而 FSDP 切分了模型参数、梯度与优化器参数，使得每张 GPU 只保留这些参数的一部分。 除了并行技术之外，FSDP 还支持将模型参数卸载至CPU，从而进一步降低显存需求。</font>

| <font style="color:rgb(0, 0, 0);">引擎</font> | <font style="color:rgb(0, 0, 0);">数据切分</font> | <font style="color:rgb(0, 0, 0);">模型切分</font> | <font style="color:rgb(0, 0, 0);">优化器切分</font> | <font style="color:rgb(0, 0, 0);">参数卸载</font> |
| --- | --- | --- | --- | --- |
| <font style="color:rgb(0, 0, 0);">DDP</font> | <font style="color:rgb(0, 0, 0);">支持</font> | <font style="color:rgb(0, 0, 0);">不支持</font> | <font style="color:rgb(0, 0, 0);">不支持</font> | <font style="color:rgb(0, 0, 0);">不支持</font> |
| <font style="color:rgb(0, 0, 0);">DeepSpeed</font> | <font style="color:rgb(0, 0, 0);">支持</font> | <font style="color:rgb(0, 0, 0);">支持</font> | <font style="color:rgb(0, 0, 0);">支持</font> | <font style="color:rgb(0, 0, 0);">支持</font> |
| <font style="color:rgb(0, 0, 0);">FSDP</font> | <font style="color:rgb(0, 0, 0);">支持</font> | <font style="color:rgb(0, 0, 0);">支持</font> | <font style="color:rgb(0, 0, 0);">支持</font> | <font style="color:rgb(0, 0, 0);">支持</font> |

**<font style="color:rgb(51, 51, 51);">分布式背景介绍</font>**

* <font style="color:rgb(51, 51, 51);">分布式计算环境中，主节点负责协调其他节点和进程的工作</font>
* <font style="color:rgb(51, 51, 51);">pytorch 官方提供的分布式训练工具 Accelerate 只支持 nvlink，而 T4，3090 这类显卡是 PIX ，检测方式：nvidia-smi topo -m；deepspeed 支持更大规模的模型训练</font>
* <font style="color:rgb(51, 51, 51);">混合精度训练</font>
* <font style="color:rgb(51, 51, 51);">ZeRO 可以减少内存占用，优化大模型训练，将模型参数分成了三个部分：Optimizer States、Gradient 和 Model Parameter。在使用 ZeRO 进行分布式训练时，可以选择 ZeRO-Offload 和 ZeRO-Stage3 等不同的优化技术。</font>

**<font style="color:rgb(51, 51, 51);">deepspeed 介绍</font>**

<font style="color:rgb(0, 0, 0);">DeepSpeed 是由微软开发的一个开源深度学习优化库，旨在提高大模型训练的效率和速度。在使用 DeepSpeed 之前，您需要先估计训练任务的显存大小，再根据任务需求与资源情况选择合适的 ZeRO 阶段。</font>

* <font style="color:rgb(0, 0, 0);">ZeRO-1: 仅划分优化器参数，每个GPU各有一份完整的模型参数与梯度。</font>
* <font style="color:rgb(0, 0, 0);">ZeRO-2: 划分优化器参数与梯度，每个GPU各有一份完整的模型参数。</font>
* <font style="color:rgb(0, 0, 0);">ZeRO-3: 划分优化器参数、梯度与模型参数。</font>

<font style="color:rgb(0, 0, 0);">简单来说：从 ZeRO-1 到 ZeRO-3，阶段数越高，显存需求越小，但是训练速度也依次变慢。此外，设置 </font><code><font style="color:rgb(0, 0, 0);">offload_param=cpu</font></code><font style="color:rgb(0, 0, 0);"> 参数会大幅减小显存需求，但会极大地使训练速度减慢。因此，如果您有足够的显存， 应当使用 ZeRO-1，并且确保 </font><code><font style="color:rgb(0, 0, 0);">offload_param=none</font></code><font style="color:rgb(0, 0, 0);">。</font>

[<font style="color:#000000;">DeepSpeed</font>](https://deepspeed.org.cn/)<font style="color:#000000;"> 是一个为速度和规模而设计的库，用于大规模模型的分布式训练，模型参数可达数十亿。其核心是零冗余优化器 (ZeRO)，它跨数据并行进程分片优化器状态 (ZeRO-1)、梯度 (ZeRO-2) 和参数 (ZeRO-3)。这大大减少了内存使用量，使您可以将训练扩展到数十亿参数的模型。为了释放更高</font><font style="color:rgb(74, 85, 101);">的内存效率，</font><font style="color:#000000;">ZeRO-Offload 通过在优化期间利用 CPU 资源来减少 GPU </font>

* <font style="color:rgb(51, 51, 51);">在 DeepSpeed 中，可以通过在配置文件中设置 “bf16.enabled”: true 来启用 BF16 混合精度训练，减少占用内存。</font>
  * <font style="color:rgb(51, 51, 51);">混合精度训练是指在训练过程中同时使用 FP16（半精度浮点数）和 FP32（单精度浮点数）两种精度的技术。</font>
* <font style="color:rgb(51, 51, 51);">deepspeed 可以根据具体情况选择合适的通信库，例如在 CPU 集群上进行分布式训练，可以选择 mpi 和 gloo；如果是在 GPU 上进行分布式训练，可以选择 nccl。</font>
  * <font style="color:rgb(51, 51, 51);">mpi 是一种跨节点通信库，常用于 CPU 集群上的分布式训练；</font>
  * <font style="color:rgb(51, 51, 51);">gloo 是一种高性能的分布式训练框架，支持 CPU 和 GPU 上的分布式训练；</font>
  * <font style="color:rgb(51, 51, 51);">nccl 是 NVIDIA 提供的 GPU 专用通信库，被广泛应用于 GPU 上的分布式训练。</font>
* <font style="color:rgb(51, 51, 51);">DeepSpeed 的核心技术：</font>
  * <font style="color:rgb(51, 51, 51);">Zero（Zero Redundancy Optimizer，3D 优化与卸载）：在 deepspeed 中通过</font><code><font style="color:rgb(51, 51, 51);">zero_optimization.stage=0/1/2/3</font></code><font style="color:rgb(51, 51, 51);"> 设置，卸载通过</font><code><font style="color:rgb(51, 51, 51);">zero_optimization.offload_optimizer.device</font></code><font style="color:rgb(51, 51, 51);">设置</font>
* <font style="color:rgb(51, 51, 51);">DeepSpeed 的推理优化技术：</font>
  * <font style="color:rgb(51, 51, 51);">Deep fusion：如下图，红色虚线框是以该单位为优化 Kernel，对应的数字是优化的效率倍数</font>
  * <font style="color:rgb(51, 51, 51);">Inference-customized GeMM</font>

### <font style="color:rgb(0, 0, 0);">单机多卡</font>

#### <font style="color:rgb(0, 0, 0);">llamafactory-cli</font>

<font style="color:rgb(0, 0, 0);">您可以使用 llamafactory-cli 启动 DeepSpeed 引擎进行单机多卡训练。</font>

```plain
FORCE_TORCHRUN=1 llamafactory-cli train examples/train_full/llama3_full_sft_ds3.yaml
```

<font style="color:rgb(0, 0, 0);">为了启动 DeepSpeed 引擎，配置文件中</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">deepspeed</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">参数指定了 DeepSpeed 配置文件的路径:</font>

```plain
...
deepspeed: examples/deepspeed/ds_z3_config.json
...
```

#### <font style="color:rgb(0, 0, 0);">deepspeed</font>

<font style="color:rgb(0, 0, 0);">您也可以使用</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">deepspeed</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">指令启动 DeepSpeed 引擎进行单机多卡训练。</font>

```plain
deepspeed --include localhost:1 your_program.py <normal cl args> --deepspeed ds_config.json
```

<font style="color:rgb(0, 0, 0);">下面是一个例子：</font>

```plain
deepspeed --num_gpus 8 src/train.py \
--deepspeed examples/deepspeed/ds_z3_config.json \
--stage sft \
--model_name_or_path meta-llama/Meta-Llama-3-8B-Instruct  \
--do_train \
--dataset alpaca_en \
--template llama3 \
--finetuning_type full \
--output_dir  saves/llama3-8b/lora/full \
--overwrite_cache \
--per_device_train_batch_size 1 \
--gradient_accumulation_steps 8 \
--lr_scheduler_type cosine \
--logging_steps 10 \
--save_steps 500 \
--learning_rate 1e-4 \
--num_train_epochs 2.0 \
--plot_loss \
--bf16
```

**<font style="color:rgb(0, 0, 0);">备注</font>**

<font style="color:rgb(0, 0, 0);">使用</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">deepspeed</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">指令启动 DeepSpeed 引擎时您无法使用</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">CUDA_VISIBLE_DEVICES</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">指定GPU。而需要：</font>

```plain
deepspeed --include localhost:1 your_program.py <normal cl args> --deepspeed ds_config.json
```

<code><font style="color:rgb(0, 0, 0);">--include</font><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">localhost:1</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">表示只是用本节点的gpu1。</font>

### <font style="color:rgb(0, 0, 0);">多机多卡</font>

<font style="color:rgb(0, 0, 0);">LLaMA-Factory 支持使用 DeepSpeed 的多机多卡训练，您可以通过以下命令启动：</font>

```plain
FORCE_TORCHRUN=1 NNODES=2 NODE_RANK=0 MASTER_ADDR=192.168.0.1 MASTER_PORT=29500 llamafactory-cli train examples/train_lora/llama3_lora_sft_ds3.yaml
FORCE_TORCHRUN=1 NNODES=2 NODE_RANK=1 MASTER_ADDR=192.168.0.1 MASTER_PORT=29500 llamafactory-cli train examples/train_lora/llama3_lora_sft_ds3.yaml
```

#### <font style="color:rgb(0, 0, 0);">deepspeed</font>

<font style="color:rgb(0, 0, 0);">您也可以使用</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">deepspeed</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">指令来启动多机多卡训练。</font>

```plain
deepspeed --num_gpus 8 --num_nodes 2 --hostfile hostfile --master_addr hostname1 --master_port=9901 \
your_program.py <normal cl args> --deepspeed ds_config.json
```

**<font style="color:rgb(0, 0, 0);">备注</font>**

* **<font style="color:rgb(0, 0, 0);">关于hostfile:</font>**

<font style="color:rgb(0, 0, 0);">hostfile的每一行指定一个节点，每行的格式为</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);"><hostname></font><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">slots=<num_slots></font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">， 其中</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);"><hostname></font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">是节点的主机名，</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);"><num_slots></font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">是该节点上的GPU数量。下面是一个例子： .. code-block:</font>

```plain
worker-1 slots=4
worker-2 slots=4
```

<font style="color:rgb(0, 0, 0);">请在</font><font style="color:rgb(0, 0, 0);"> </font><https://www.deepspeed.ai/getting-started/><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">了解更多。</font>

* <font style="color:rgb(0, 0, 0);">如果没有指定</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">hostfile</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">变量, DeepSpeed 会搜索</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">/job/hostfile</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">文件。如果仍未找到，那么 DeepSpeed 会使用本机上所有可用的GPU。</font>

#### <font style="color:rgb(0, 0, 0);">accelerate</font>

<font style="color:rgb(0, 0, 0);">您还可以使用</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">accelerate</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">指令启动 DeepSpeed 引擎。 首先通过以下命令生成 DeepSpeed 配置文件：</font>

```plain
main_process_port: 29500

mixed_precision: fp16
num_machines: 2
num_processes: 16
rdzv_backend: static
same_network: true
tpu_env: []

tpu_use_sudo: false

```
