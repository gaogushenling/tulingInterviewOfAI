## <font style="color:#000000;">📋</font><font style="color:#000000;"> 全局选项</font>

### <font style="color:#000000;">基础选项</font>

**<font style="color:#000000;">bash</font>**

```plain
-V, --version                         输出版本号
-h, --help                            显示帮助信息
-d, --debug                           启用调试模式 (默认: false)
    --verbose                         覆盖配置中的详细模式设置 (默认: false)
-p, --print                           打印响应并退出 (适用于管道) (默认: false)
```

### <font style="color:#000000;">输入输出格式</font>

**<font style="color:#000000;">bash</font>**

```plain
--output-format <format>              输出格式 (仅与 --print 配合使用):
                                      "text" (默认), "json" (单个结果),
                                      或 "stream-json" (实时流式)
--input-format <format>               输入格式 (仅与 --print 配合使用):
                                      "text" (默认), 或 "stream-json"
                                      (实时流式输入)
```

### <font style="color:#000000;">会话管理</font>

**<font style="color:#000000;">bash</font>**

```plain
-c, --continue                        继续最近的对话 (默认: false)
-r, --resume [sessionId]              恢复对话 - 提供会话ID或交互式选择
    --session-id <uuid>               使用特定的会话ID (必须是有效的UUID)
```

### <font style="color:#000000;">AI 模型选项</font>

**<font style="color:#000000;">bash</font>**

```plain
--model <model>                       当前会话的模型。提供模型名称
                                      (如 'gpt-5' 或 'gpt-4')
--fallback-model <model>              当默认模型过载时自动回退到指定模型
                                      (仅与 --print 配合使用)
```

### <font style="color:#000000;">安全和权限</font>

**<font style="color:#000000;">bash</font>**

```plain
--dangerously-skip-permissions        绕过所有权限检查。仅推荐用于无网络访问的沙箱
--permission-mode <mode>              权限模式: "acceptEdits", "bypassPermissions", 
                                      "default", "plan"
                                      支持会话级动态管理，UI实时显示当前状态
--allowedTools <tools...>             允许的工具列表 (如 "Bash(git:*) Edit")
--disallowedTools <tools...>          禁止的工具列表 (如 "Bash(git:*) Edit")
--add-dir <directories...>            允许工具访问的额外目录
```

### <font style="color:#000000;">MCP 集成</font>

**<font style="color:#000000;">bash</font>**

```plain
--mcp-config <fileOrString>           从JSON文件或字符串加载MCP服务器
--strict-mcp-config                   仅使用 --mcp-config 中的MCP服务器，
                                      忽略其他MCP配置 (默认: false)
```

### <font style="color:#000000;">IDE 集成</font>

**<font style="color:#000000;">bash</font>**

```plain
--ide                                 如果有且仅有一个有效IDE可用，
                                      启动时自动连接 (默认: false)
```

```plain
# 跳过权限检查 (谨慎使用，-p 模式下的必需参数)
codebuddy --dangerously-skip-permissions -p "执行需要授权的操作"
```

<font style="color:#000000;">这是 CodeBuddy Code 最强大的功能之一。您可以将常用的提示(Prompts)、脚本和工作流封装成可复用的自定义命令,从而极大地提升效率。</font>

<font style="color:#000000;">自定义命令通过在特定目录中创建</font><font style="color:#000000;"> </font><code><font style="color:#000000;">.md</font></code><font style="color:#000000;"> </font><font style="color:#000000;">(Markdown) 文件来定义。</font>

## 常见问题

### Q: 抓取失败怎么办？

A: 检查网络连接、URL是否正确、是否有反爬虫限制

### Q: 预测准确率不高？

A: 需要足够的历史数据，建议至少30条记录

### Q: 如何添加新平台支持？

A: 在`web_scraper.py`中添加对应平台的解析规则
