### 如何加载 CSV 文件

[<font style="color:rgb(28, 30, 33);">逗号分隔值（CSV）</font>](https://zh.wikipedia.org/wiki/%E9%80%97%E5%8F%B7%E5%88%86%E9%9A%94%E5%80%BC)<font style="color:rgb(28, 30, 33);">文件是一种使用逗号分隔值的定界文本文件。文件的每一行是一个数据记录。每个记录由一个或多个字段组成，字段之间用逗号分隔。</font>

<font style="color:rgb(28, 30, 33);">LangChain 实现了一个</font><font style="color:rgb(28, 30, 33);"> </font>[<font style="color:rgb(28, 30, 33);">CSV 加载器</font>](https://api.python.langchain.com/en/latest/document_loaders/langchain_community.document_loaders.csv_loader.CSVLoader.html)<font style="color:rgb(28, 30, 33);">，可以将 CSV 文件加载为一系列</font><font style="color:rgb(28, 30, 33);"> </font>[<font style="color:rgb(28, 30, 33);">Document</font>](https://api.python.langchain.com/en/latest/documents/langchain_core.documents.base.Document.html#langchain_core.documents.base.Document)<font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">对象。CSV 文件的每一行都会被翻译为一个文档。</font>

```python
#示例：csv_loader.py
from langchain_community.document_loaders.csv_loader import CSVLoader

file_path = (
    "../../resource/doc_search.csv"
)
loader = CSVLoader(file_path=file_path,encoding="UTF-8")
data = loader.load()
for record in data[:2]:
    print(record)
```

#### 自定义 CSV 解析和加载

<code><font style="color:rgb(28, 30, 33);">CSVLoader</font></code><font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">接受一个</font><font style="color:rgb(28, 30, 33);"> </font><code><font style="color:rgb(28, 30, 33);">csv_args</font></code><font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">关键字参数，用于自定义传递给 Python 的</font><font style="color:rgb(28, 30, 33);"> </font><code><font style="color:rgb(28, 30, 33);">csv.DictReader</font></code><font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">的参数。有关支持的 csv 参数的更多信息，请参阅</font><font style="color:rgb(28, 30, 33);"> </font>[<font style="color:rgb(28, 30, 33);">csv 模块</font>](https://docs.python.org/zh-cn/3/library/csv.html)<font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">文档。</font>

```python
#示例：csv_custom.py
from langchain_community.document_loaders.csv_loader import CSVLoader

file_path = (
    "../../resource/doc_search.csv"
)
loader = CSVLoader(
    file_path=file_path,
    encoding="UTF-8",
    csv_args={
        "delimiter": ",",
        "quotechar": '"',
        "fieldnames": ["Name", "Species", "Age", "Habitat"],
    },
)
data = loader.load()
for record in data[:2]:
    print(record)
```

### <font style="color:rgb(28, 30, 33);">如何加载 Markdown</font>

[<font style="color:rgb(28, 30, 33);">Markdown</font>](https://en.wikipedia.org/wiki/Markdown)<font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">是一种轻量级标记语言，可用于使用纯文本编辑器创建格式化文本。</font>

<font style="color:rgb(28, 30, 33);">在这里，我们将介绍如何将</font><font style="color:rgb(28, 30, 33);"> </font><code><font style="color:rgb(28, 30, 33);">Markdown</font></code><font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">文档加载到 LangChain</font><font style="color:rgb(28, 30, 33);"> </font>[<font style="color:rgb(28, 30, 33);">Document</font>](https://api.python.langchain.com/en/latest/documents/langchain_core.documents.base.Document.html#langchain_core.documents.base.Document)<font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">对象中，以便在下游使用。</font>

<font style="color:rgb(28, 30, 33);">我们将介绍：</font>

* <font style="color:rgb(28, 30, 33);">基本用法；</font>

<font style="color:rgb(28, 30, 33);">LangChain 实现了一个</font><font style="color:rgb(28, 30, 33);"> </font>[<font style="color:rgb(28, 30, 33);">UnstructuredMarkdownLoader</font>](https://api.python.langchain.com/en/latest/document_loaders/langchain_community.document_loaders.markdown.UnstructuredMarkdownLoader.html)<font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">对象，它需要使用</font><font style="color:rgb(28, 30, 33);"> </font>[<font style="color:rgb(28, 30, 33);">Unstructured</font>](https://unstructured-io.github.io/unstructured/)<font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">包。首先我们需要安装它：</font>

```python
# !pip install "unstructured[md]"
```

<font style="color:rgb(28, 30, 33);">基本用法将会将一个 Markdown 文件加载到单个文档中。这里我们演示了在 LangChain 的 readme 上的操作：</font>

```python
from langchain_community.document_loaders import UnstructuredMarkdownLoader

markdown_path = "../../resource/langchain.md"
```

#### <font style="color:rgb(28, 30, 33);">保留元素</font>

<font style="color:rgb(28, 30, 33);">在幕后，Unstructured 为不同的文本块创建了不同的 "元素"。默认情况下，我们将它们组合在一起，但是您可以通过指定</font><font style="color:rgb(28, 30, 33);"> </font><code><font style="color:rgb(28, 30, 33);">mode="elements"</font></code><font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">轻松保留这种分离。</font>

```python
markdown_path = "../../resource/langchain.md"

for document in data[:2]:
    print(f"{document}\n")
```

#### 使用 Unstructured

[<font style="color:rgb(28, 30, 33);">Unstructured</font>](https://unstructured-io.github.io/unstructured/)<font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">支持一个通用接口，用于处理非结构化或半结构化文件格式，例如 Markdown 或 PDF。LangChain 的</font><font style="color:rgb(28, 30, 33);"> </font>[<font style="color:rgb(28, 30, 33);">UnstructuredPDFLoader</font>](https://api.python.langchain.com/en/latest/document_loaders/langchain_community.document_loaders.pdf.UnstructuredPDFLoader.html)<font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">与 Unstructured 集成，将 PDF 文档解析为 LangChain</font><font style="color:rgb(28, 30, 33);"> </font>[<font style="color:rgb(28, 30, 33);">Document</font>](https://api.python.langchain.com/en/latest/documents/langchain_core.documents.base.Document.html)<font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">对象。</font>

```python
from langchain_community.document_loaders import UnstructuredPDFLoader
file_path = (
    "../../resource/pytorch.pdf"
)
loader = UnstructuredPDFLoader(file_path)
data = loader.load()
```

##### 保留元素

<font style="color:rgb(28, 30, 33);">在幕后，Unstructured 为不同的文本块创建不同的 "元素"。默认情况下，我们将它们合并在一起，但您可以通过指定</font><font style="color:rgb(28, 30, 33);"> </font><code><font style="color:rgb(28, 30, 33);">mode="elements"</font></code><font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">轻松保持分离。</font>

```python
file_path = (
    "../../resource/pytorch.pdf"
)
loader = UnstructuredPDFLoader(file_path, mode="elements")
data = loader.load()
data[0]
```

##### 使用 Unstructured 加载远程 PDF

<font style="color:rgb(28, 30, 33);">这涵盖了如何将在线 PDF 加载到我们可以在下游使用的文档格式中。这可用于各种在线 PDF 站点，如</font><font style="color:rgb(28, 30, 33);"> </font>[<font style="color:rgb(28, 30, 33);">https://open.umn.edu/opentextbooks/textbooks/</font>](https://open.umn.edu/opentextbooks/textbooks/)<font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">和</font><font style="color:rgb(28, 30, 33);"> </font>[<font style="color:rgb(28, 30, 33);">https://arxiv.org/archive/</font>](https://arxiv.org/archive/)<font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">注意：所有其他 PDF 加载器也可以用于获取远程 PDF，但</font><font style="color:rgb(28, 30, 33);"> </font><code><font style="color:rgb(28, 30, 33);">OnlinePDFLoader</font></code><font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">是一个旧函数，专门与</font><font style="color:rgb(28, 30, 33);"> </font><code><font style="color:rgb(28, 30, 33);">UnstructuredPDFLoader</font></code><font style="color:rgb(28, 30, 33);"> </font><font style="color:rgb(28, 30, 33);">配合使用。</font>

```python
from langchain_community.document_loaders import OnlinePDFLoader
loader = OnlinePDFLoader("https://arxiv.org/pdf/2302.03803.pdf")
data = loader.load()
```
