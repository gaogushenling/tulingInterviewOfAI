# 63.基于Windsurf实现类Manus功能

<font style="color:rgb(51, 51, 51);">官网：</font>[https://codeium.com/windsurf](https://codeium.com/windsurf)

**<font style="color:rgb(51, 51, 51);">主要功能</font>**

1. <font style="color:rgb(51, 51, 51);">‌</font>**<font style="color:rgb(51, 51, 51);">Flows模式</font>**<font style="color:rgb(51, 51, 51);">‌：Winsurf引入了一种全新的协作智能体（Flow），能够实时捕捉并响应开发者的动作，提供高度同步的编程体验。这种模式包括Agent模式和Copilot模式，前者独立处理复杂任务，后者实时协助用户完成代码编辑‌</font>12<font style="color:rgb(51, 51, 51);">。</font>
2. <font style="color:rgb(51, 51, 51);">‌</font>**<font style="color:rgb(51, 51, 51);">深度上下文感知</font>**<font style="color:rgb(51, 51, 51);">‌：利用先进的自然语言处理（NLP）和深度学习技术，Winsurf能够深入理解代码的上下文，包括变量类型、函数定义、类结构等，不断优化其模型，以提高建议的准确性和实用性‌</font>2<font style="color:rgb(51, 51, 51);">。</font>
3. <font style="color:rgb(51, 51, 51);">‌</font>**<font style="color:rgb(51, 51, 51);">多模型AI集成</font>**<font style="color:rgb(51, 51, 51);">‌：结合了多种AI模型，如代码生成模型、错误检测模型、重构建议模型等，为开发者提供全方位、多层次的编程支持‌</font>2<font style="color:rgb(51, 51, 51);">。</font>
4. <font style="color:rgb(51, 51, 51);">‌</font>**<font style="color:rgb(51, 51, 51);">Cascade功能</font>**<font style="color:rgb(51, 51, 51);">‌：支持自然语言生成命令并执行，甚至可以检测和修复代码中的问题‌</font>1<font style="color:rgb(51, 51, 51);">。</font>
5. <font style="color:rgb(51, 51, 51);">‌</font>**<font style="color:rgb(51, 51, 51);">多文件编辑</font>**<font style="color:rgb(51, 51, 51);">‌：跨文件一致修改，优化代码的整体连贯性‌</font>1<font style="color:rgb(51, 51, 51);">。</font>
6. <font style="color:rgb(51, 51, 51);">‌</font>**<font style="color:rgb(51, 51, 51);">命令行增强</font>**<font style="color:rgb(51, 51, 51);">‌：支持自然语言输入操作终端命令，简化流程‌</font>1<font style="color:rgb(51, 51, 51);">。</font>
7. <font style="color:rgb(51, 51, 51);">‌</font>**<font style="color:rgb(51, 51, 51);">@引用功能</font>**<font style="color:rgb(51, 51, 51);">‌：快速定位并引用函数、类、文件或目录，提高效率‌</font>1<font style="color:rgb(51, 51, 51);">。</font>

<font style="color:rgb(34, 34, 34);">Manus先是爆火，又是被暴骂。但坦率讲，有些指标是不能做假的，所以其能力还是在那里的。只是从实验室可用到工程可用，还有很多成本、稳定性方面的挑战。Manus的爆火至少有以下的客观好处：</font>

<font style="color:rgb(34, 34, 34);">1、让多数普通人了解到了什么是Agent，在简单的聊天对话形式以外，还有很多其他的形式。</font>

<font style="color:rgb(34, 34, 34);">2、用户界面的体验很好，在多数Agent模式中，给到用户的都是黑箱；但用户往往很需要“掌控感”。这给了很多做Agent的项目很好的参考。</font>

<font style="color:rgb(34, 34, 34);">3、全过程可分享的思考和执行过程，而不仅仅是结果数据，天生带有很强的</font><font style="color:rgb(34, 34, 34);">推广属性（尤其还加速了）</font>

<font style="color:rgb(34, 34, 34);">4、促进了两个比较好的项目的开源，Camel-AI Owl和Open Manus。</font>

<font style="color:rgb(34, 34, 34);">从主观上，我对于Manus有一些可以学习</font>

<font style="color:rgb(34, 34, 34);">1、显示地把计划列出来，然后一步一步执行，并同步修改进度</font>

<font style="color:rgb(34, 34, 34);">2、信息采集，使用AI搜索与浏览器视觉识别结合的方式开展，这样一些页面效果的信息可以采集</font>

<font style="color:rgb(34, 34, 34);">3、输出物，使用可视化输出的方式来输出</font>

<font style="color:rgb(34, 34, 34);">准备工作环境：</font>

<font style="color:rgb(34, 34, 34);">新建了一个文件夹，就叫做“使用windsurf做一些manus”。最新版的Windsurf，已经支持了可以设置 rules。具体的设置方式是：通过右下角的“Windsurf - Settings”，点击“Memories and Rules”，点击 Manage</font>

<font style="color:rgb(34, 34, 34);">在弹出页面中，Edit workspace rules，来设置当前工作区的规则。</font>

![1742344407122-20295630-c317-462a-964c-a27445b9d4e2.png](./img/oPlX9i1qc8teeobj/1742344407122-20295630-c317-462a-964c-a27445b9d4e2-082779.png)

<font style="color:rgb(34, 34, 34);">此时，系统会自动打开一个叫做  .windsurfrules ，这个文件中的内容，就是每次交易执行过程中，会固定发送给模型的话语。以下是我写的一份效果还不错的 .windsurfrules 内容，你也可以根据自己的需要进行调整：</font>

<font style="color:rgb(159, 160, 165);">- Speak in Chinese</font>

<font style="color:rgb(159, 160, 165);">- You are a assistant, when you get a task, you will do it step by step. you will generate a todo.md, and you will update it when you finish a step.</font>

<font style="color:rgb(159, 160, 165);">- If you get data analysis task, you will use Python-based data science</font>

<font style="color:rgb(159, 160, 165);">- Use Python 3.12 as the primary programming language</font>

<font style="color:rgb(159, 160, 165);">- Use NumPy for numerical computing and array operations</font>

<font style="color:rgb(159, 160, 165);">- Use Pandas for data manipulation and analysis</font>

<font style="color:rgb(159, 160, 165);">- Use uv for environment and package management</font>

<font style="color:rgb(159, 160, 165);">- Use Dash for web based report</font>

<font style="color:rgb(159, 160, 165);">- Use a seperated file to Generate a web based report, pretty, modern and interactive</font>

<font style="color:rgb(159, 160, 165);">- Run a web server And give me the url</font>

<font style="color:rgb(159, 160, 165);">- Use Website Preview and firecrawl to get web content</font>

<font style="color:rgb(159, 160, 165);">- Use a seperated file to store project summary</font>

<font style="color:rgb(159, 160, 165);">- Use a seperated file to store todo list</font>

<font style="color:rgb(159, 160, 165);">- Use a seperated directory to store all files from one task</font>

<font style="color:rgb(159, 160, 165);">- Store all process data in files under the task directory</font>

<font style="color:rgb(34, 34, 34);">简单解释一下：</font>

<font style="color:rgb(34, 34, 34);">- 首先确认让他说中文</font>

<font style="color:rgb(34, 34, 34);">- 要求接到任务时，先整理一个todo.md文件，用于存放步骤的列表，然后一步一步执行，并且每执行一步都更新一下这个列表。</font>

<font style="color:rgb(34, 34, 34);">- 特别地，如果一个数据分析任务，要求使用python语言来编写数据分析程序</font>

<font style="color:rgb(34, 34, 34);">- 接着规划python的版本以及一些库</font>

<font style="color:rgb(34, 34, 34);">- 使用uv作为python虚拟环境的管理（这里要注意，我是使用的uv，如果你是使用conda的，请对应更改，当然，大多数时候，windsurf会自动帮你解决）</font>

<font style="color:rgb(34, 34, 34);">- 接下来要求使用图形化的web方式输出结果</font>

<font style="color:rgb(34, 34, 34);">- 每个任务独立存储数据文件和结果</font>

<font style="color:rgb(34, 34, 34);">配置windsurf自动执行命令</font>

<font style="color:rgb(34, 34, 34);">至此，功能已经可用了，但要达到自动化的效果，同样需要点击右下角的 windsurf-settings，然后把 Terminal Auto Execution，设置为 Turbo。</font>
