# <font style="color:rgb(31, 35, 40);">微调预训练模型</font>

<font style="color:rgb(31, 35, 40);">使用预训练模型有许多显著的好处。它降低了计算成本，减少了碳排放，同时允许您使用最先进的模型，而无需从头开始训练一个。</font><font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Transformers 提供了涉及各种任务的成千上万的预训练模型。当您使用预训练模型时，您需要在与任务相关的数据集上训练该模型。这种操作被称为微调，是一种非常强大的训练技术。在本教程中，您将使用您选择的深度学习框架来微调一个预训练模型：</font>

* <font style="color:rgb(31, 35, 40);">使用 </font><font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Transformers 的 \[</font><code><font style="color:rgb(31, 35, 40);">Trainer</font></code><font style="color:rgb(31, 35, 40);">] 来微调预训练模型。</font>
* <font style="color:rgb(31, 35, 40);">在 TensorFlow 中使用 Keras 来微调预训练模型。</font>
* <font style="color:rgb(31, 35, 40);">在原生 PyTorch 中微调预训练模型。</font>

<font style="color:rgb(31, 35, 40);">首先，加载</font>[Yelp评论](https://huggingface.co/datasets/yelp_review_full)<font style="color:rgb(31, 35, 40);">数据集：</font>

```plain
>>> from datasets import load_dataset

>>> dataset = load_dataset("yelp_review_full")
>>> dataset["train"][100]
```

<font style="color:rgb(31, 35, 40);">正如您现在所知，您需要一个</font><code><font style="color:rgb(31, 35, 40);">tokenizer</font></code><font style="color:rgb(31, 35, 40);">来处理文本，包括填充和截断操作以处理可变的序列长度。如果要一次性处理您的数据集，可以使用 </font><font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Datasets 的</font><font style="color:rgb(31, 35, 40);"> </font>[map](https://huggingface.co/docs/datasets/process#map)<font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">方法，将预处理函数应用于整个数据集：</font>

```plain
>>> from transformers import AutoTokenizer

>>> tokenizer = AutoTokenizer.from_pretrained("google-bert/bert-base-cased")


>>> def tokenize_function(examples):
...     return tokenizer(examples["text"], padding="max_length", truncation=True)


>>> tokenized_datasets = dataset.map(tokenize_function, batched=True)
```

<font style="color:rgb(31, 35, 40);">如果愿意的话，您可以从完整数据集提取一个较小子集来进行微调，以减少训练所需的时间：</font>

```plain
>>> small_train_dataset = tokenized_datasets["train"].shuffle(seed=42).select(range(1000))
>>> small_eval_dataset = tokenized_datasets["test"].shuffle(seed=42).select(range(1000))
```

## <font style="color:rgb(31, 35, 40);">使用 PyTorch Trainer 进行训练</font>

<font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Transformers 提供了一个专为训练 </font><font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Transformers 模型而优化的 \[</font><code><font style="color:rgb(31, 35, 40);">Trainer</font></code><font style="color:rgb(31, 35, 40);">] 类，使您无需手动编写自己的训练循环步骤而更轻松地开始训练模型。\[</font><code><font style="color:rgb(31, 35, 40);">Trainer</font></code><font style="color:rgb(31, 35, 40);">] API 支持各种训练选项和功能，如日志记录、梯度累积和混合精度。</font>

<font style="color:rgb(31, 35, 40);">首先加载您的模型并指定期望的标签数量。根据 Yelp Review</font><font style="color:rgb(31, 35, 40);"> </font>[数据集卡片](https://huggingface.co/datasets/yelp_review_full#data-fields)<font style="color:rgb(31, 35, 40);">，您知道有五个标签：</font>

```plain
>>> from transformers import AutoModelForSequenceClassification

>>> model = AutoModelForSequenceClassification.from_pretrained("google-bert/bert-base-cased", num_labels=5)
```

<font style="color:rgb(31, 35, 40);">您将会看到一个警告，提到一些预训练权重未被使用，以及一些权重被随机初始化。不用担心，这是完全正常的！BERT 模型的预训练</font><code><font style="color:rgb(31, 35, 40);">head</font></code><font style="color:rgb(31, 35, 40);">被丢弃，并替换为一个随机初始化的分类</font><code><font style="color:rgb(31, 35, 40);">head</font></code><font style="color:rgb(31, 35, 40);">。您将在您的序列分类任务上微调这个新模型</font><code><font style="color:rgb(31, 35, 40);">head</font></code><font style="color:rgb(31, 35, 40);">，将预训练模型的知识转移给它。</font>

### <font style="color:rgb(31, 35, 40);">训练超参数</font>

<font style="color:rgb(31, 35, 40);">接下来，创建一个 \[</font><code><font style="color:rgb(31, 35, 40);">TrainingArguments</font></code><font style="color:rgb(31, 35, 40);">] 类，其中包含您可以调整的所有超参数以及用于激活不同训练选项的标志。对于本教程，您可以从默认的训练</font>[超参数](https://huggingface.co/docs/transformers/main_classes/trainer#transformers.TrainingArguments)<font style="color:rgb(31, 35, 40);">开始，但随时可以尝试不同的设置以找到最佳设置。</font>

<font style="color:rgb(31, 35, 40);">指定保存训练检查点的位置：</font>

```plain
>>> from transformers import TrainingArguments

>>> training_args = TrainingArguments(output_dir="test_trainer")
```

### <font style="color:rgb(31, 35, 40);">评估</font>

<font style="color:rgb(31, 35, 40);">\[</font><code><font style="color:rgb(31, 35, 40);">Trainer</font></code><font style="color:rgb(31, 35, 40);">] 在训练过程中不会自动评估模型性能。您需要向 \[</font><code><font style="color:rgb(31, 35, 40);">Trainer</font></code><font style="color:rgb(31, 35, 40);">] 传递一个函数来计算和展示指标。</font>[🤗 Evaluate](https://huggingface.co/docs/evaluate/index)<font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">库提供了一个简单的</font><font style="color:rgb(31, 35, 40);"> </font>[accuracy](https://huggingface.co/spaces/evaluate-metric/accuracy)<font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">函数，您可以使用 \[</font><code><font style="color:rgb(31, 35, 40);">evaluate.load</font></code><font style="color:rgb(31, 35, 40);">] 函数加载它（有关更多信息，请参阅此</font>[快速入门](https://huggingface.co/docs/evaluate/a_quick_tour)<font style="color:rgb(31, 35, 40);">）：</font>

```plain
>>> import numpy as np
>>> import evaluate

>>> metric = evaluate.load("accuracy")
```

<font style="color:rgb(31, 35, 40);">在</font><font style="color:rgb(31, 35, 40);"> </font><code><font style="color:rgb(31, 35, 40);">metric</font></code><font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">上调用 \[</font><code><font style="color:rgb(31, 35, 40);">~evaluate.compute</font></code><font style="color:rgb(31, 35, 40);">] 来计算您的预测的准确性。在将预测传递给</font><font style="color:rgb(31, 35, 40);"> </font><code><font style="color:rgb(31, 35, 40);">compute</font></code><font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">之前，您需要将预测转换为</font><code><font style="color:rgb(31, 35, 40);">logits</font></code><font style="color:rgb(31, 35, 40);">（请记住，所有 </font><font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Transformers 模型都返回对</font><code><font style="color:rgb(31, 35, 40);">logits</font></code><font style="color:rgb(31, 35, 40);">）：</font>

```plain
>>> def compute_metrics(eval_pred):
...     logits, labels = eval_pred
...     predictions = np.argmax(logits, axis=-1)
...     return metric.compute(predictions=predictions, references=labels)
```

<font style="color:rgb(31, 35, 40);">如果您希望在微调过程中监视评估指标，请在您的训练参数中指定</font><font style="color:rgb(31, 35, 40);"> </font><code><font style="color:rgb(31, 35, 40);">eval_strategy</font></code><font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">参数，以在每个</font><code><font style="color:rgb(31, 35, 40);">epoch</font></code><font style="color:rgb(31, 35, 40);">结束时展示评估指标：</font>

```plain
>>> from transformers import TrainingArguments, Trainer

>>> training_args = TrainingArguments(output_dir="test_trainer", eval_strategy="epoch")
```

### <font style="color:rgb(31, 35, 40);">训练器</font>

<font style="color:rgb(31, 35, 40);">创建一个包含您的模型、训练参数、训练和测试数据集以及评估函数的 \[</font><code><font style="color:rgb(31, 35, 40);">Trainer</font></code><font style="color:rgb(31, 35, 40);">] 对象：</font>

```plain
>>> trainer = Trainer(
...     model=model,
...     args=training_args,
...     train_dataset=small_train_dataset,
...     eval_dataset=small_eval_dataset,
...     compute_metrics=compute_metrics,
... )
```

<font style="color:rgb(31, 35, 40);">然后调用\[</font><code><font style="color:rgb(31, 35, 40);">~transformers.Trainer.train</font></code><font style="color:rgb(31, 35, 40);">]以微调模型：</font>

<font style="color:rgb(31, 35, 40);">>>> trainer.train()</font>

## <font style="color:rgb(31, 35, 40);">使用keras训练TensorFlow模型</font>

<font style="color:rgb(31, 35, 40);">您也可以使用 Keras API 在 TensorFlow 中训练 </font><font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Transformers 模型！</font>

### <font style="color:rgb(31, 35, 40);">加载用于 Keras 的数据</font>

<font style="color:rgb(31, 35, 40);">当您希望使用 Keras API 训练 </font><font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Transformers 模型时，您需要将您的数据集转换为 Keras 可理解的格式。如果您的数据集很小，您可以将整个数据集转换为NumPy数组并传递给 Keras。在进行更复杂的操作之前，让我们先尝试这种方法。</font>

<font style="color:rgb(31, 35, 40);">首先，加载一个数据集。我们将使用</font><font style="color:rgb(31, 35, 40);"> </font>[GLUE benchmark](https://huggingface.co/datasets/glue)<font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">中的 CoLA 数据集，因为它是一个简单的二元文本分类任务。现在只使用训练数据集。</font>

```plain
from datasets import load_dataset

dataset = load_dataset("glue", "cola")
dataset = dataset["train"]  # Just take the training split for now
```

<font style="color:rgb(31, 35, 40);">接下来，加载一个</font><code><font style="color:rgb(31, 35, 40);">tokenizer</font></code><font style="color:rgb(31, 35, 40);">并将数据标记为 NumPy 数组。请注意，标签已经是由 0 和 1 组成的</font><code><font style="color:rgb(31, 35, 40);">list</font></code><font style="color:rgb(31, 35, 40);">，因此我们可以直接将其转换为 NumPy 数组而无需进行分词处理！</font>

```plain
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("google-bert/bert-base-cased")
tokenized_data = tokenizer(dataset["sentence"], return_tensors="np", padding=True)
# Tokenizer returns a BatchEncoding, but we convert that to a dict for Keras
tokenized_data = dict(tokenized_data)

labels = np.array(dataset["label"])  # Label is already an array of 0 and 1
```

<font style="color:rgb(31, 35, 40);">最后，加载、</font>[compile](https://keras.io/api/models/model_training_apis/#compile-method)<font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">和</font><font style="color:rgb(31, 35, 40);"> </font>[fit](https://keras.io/api/models/model_training_apis/#fit-method)<font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">模型。请注意，Transformers 模型都有一个默认的与任务相关的损失函数，因此除非您希望自定义，否则无需指定一个损失函数：</font>

```plain
from transformers import TFAutoModelForSequenceClassification
from tensorflow.keras.optimizers import Adam

# Load and compile our model
model = TFAutoModelForSequenceClassification.from_pretrained("google-bert/bert-base-cased")
# Lower learning rates are often better for fine-tuning transformers
model.compile(optimizer=Adam(3e-5))  # No loss argument!

model.fit(tokenized_data, labels)
```

<font style="color:rgb(31, 35, 40);">当您使用</font><font style="color:rgb(31, 35, 40);"> </font><code><font style="color:rgb(31, 35, 40);">compile()</font></code><font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">编译模型时，无需传递损失参数！如果不指定损失参数，Hugging Face 模型会自动选择适合其任务和模型架构的损失函数。如果需要，您始终可以自己指定损失函数以覆盖默认配置。</font>

<font style="color:rgb(31, 35, 40);">这种方法对于较小的数据集效果很好，但对于较大的数据集，您可能会发现它开始变得有问题。为什么呢？因为分词后的数组和标签必须完全加载到内存中，而且由于 NumPy 无法处理“不规则”数组，因此每个分词后的样本长度都必须被填充到数据集中最长样本的长度。这将使您的数组变得更大，而所有这些</font><code><font style="color:rgb(31, 35, 40);">padding tokens</font></code><font style="color:rgb(31, 35, 40);">也会减慢训练速度！</font>

### <font style="color:rgb(31, 35, 40);">将数据加载为 tf.data.Dataset</font>

<font style="color:rgb(31, 35, 40);">如果您想避免训练速度减慢，可以将数据加载为</font><font style="color:rgb(31, 35, 40);"> </font><code><font style="color:rgb(31, 35, 40);">tf.data.Dataset</font></code><font style="color:rgb(31, 35, 40);">。虽然您可以自己编写自己的</font><font style="color:rgb(31, 35, 40);"> </font><code><font style="color:rgb(31, 35, 40);">tf.data</font></code><font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">流水线，但我们有两种方便的方法来实现这一点：</font>

* <font style="color:rgb(31, 35, 40);">\[</font><code><font style="color:rgb(31, 35, 40);">~TFPreTrainedModel.prepare_tf_dataset</font></code><font style="color:rgb(31, 35, 40);">]：这是我们在大多数情况下推荐的方法。因为它是模型上的一个方法，它可以检查模型以自动确定哪些列可用作模型输入，并丢弃其他列以创建一个更简单、性能更好的数据集。</font>
* <font style="color:rgb(31, 35, 40);">\[</font><code><font style="color:rgb(31, 35, 40);">~datasets.Dataset.to_tf_dataset</font></code><font style="color:rgb(31, 35, 40);">]：这个方法更低级，但当您希望完全控制数据集的创建方式时非常有用，可以通过指定要包括的确切</font><font style="color:rgb(31, 35, 40);"> </font><code><font style="color:rgb(31, 35, 40);">columns</font></code><font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">和</font><font style="color:rgb(31, 35, 40);"> </font><code><font style="color:rgb(31, 35, 40);">label_cols</font></code><font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">来实现。</font>

<font style="color:rgb(31, 35, 40);">在使用 \[</font><code><font style="color:rgb(31, 35, 40);">~TFPreTrainedModel.prepare_tf_dataset</font></code><font style="color:rgb(31, 35, 40);">] 之前，您需要将</font><code><font style="color:rgb(31, 35, 40);">tokenizer</font></code><font style="color:rgb(31, 35, 40);">的输出添加到数据集作为列，如下面的代码示例所示：</font>

```plain
def tokenize_dataset(data):
    # Keys of the returned dictionary will be added to the dataset as columns
    return tokenizer(data["text"])


dataset = dataset.map(tokenize_dataset)
```

<font style="color:rgb(31, 35, 40);">请记住，默认情况下，Hugging Face 数据集存储在硬盘上，因此这不会增加您的内存使用！一旦列已经添加，您可以从数据集中流式的传输批次数据，并为每个批次添加</font><code><font style="color:rgb(31, 35, 40);">padding tokens</font></code><font style="color:rgb(31, 35, 40);">，这与为整个数据集添加</font><code><font style="color:rgb(31, 35, 40);">padding tokens</font></code><font style="color:rgb(31, 35, 40);">相比，大大减少了</font><code><font style="color:rgb(31, 35, 40);">padding tokens</font></code><font style="color:rgb(31, 35, 40);">的数量。</font>

<font style="color:rgb(31, 35, 40);">>>> tf_dataset = model.prepare_tf_dataset(dataset\["train"], batch_size=16, shuffle=True, tokenizer=tokenizer)</font>

<font style="color:rgb(31, 35, 40);">请注意，在上面的代码示例中，您需要将</font><code><font style="color:rgb(31, 35, 40);">tokenizer</font></code><font style="color:rgb(31, 35, 40);">传递给</font><code><font style="color:rgb(31, 35, 40);">prepare_tf_dataset</font></code><font style="color:rgb(31, 35, 40);">，以便它可以在加载批次时正确填充它们。如果数据集中的所有样本都具有相同的长度而且不需要填充，您可以跳过此参数。如果需要执行比填充样本更复杂的操作（例如，用于掩码语言模型的</font><code><font style="color:rgb(31, 35, 40);">tokens</font></code><font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">替换），则可以使用</font><font style="color:rgb(31, 35, 40);"> </font><code><font style="color:rgb(31, 35, 40);">collate_fn</font></code><font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">参数，而不是传递一个函数来将样本列表转换为批次并应用任何所需的预处理。请查看我们的</font>[示例](https://github.com/huggingface/transformers/tree/main/examples)<font style="color:rgb(31, 35, 40);">或</font>[笔记](https://huggingface.co/docs/transformers/notebooks)<font style="color:rgb(31, 35, 40);">以了解此方法的实际操作。</font>

<font style="color:rgb(31, 35, 40);">一旦创建了</font><font style="color:rgb(31, 35, 40);"> </font><code><font style="color:rgb(31, 35, 40);">tf.data.Dataset</font></code><font style="color:rgb(31, 35, 40);">，您可以像以前一样编译和训练模型：</font>

```plain
model.compile(optimizer=Adam(3e-5))  # No loss argument!

model.fit(tf_dataset)
```

## <font style="color:rgb(31, 35, 40);">在原生 PyTorch 中训练</font>

<font style="color:rgb(31, 35, 40);">\[</font><code><font style="color:rgb(31, 35, 40);">Trainer</font></code><font style="color:rgb(31, 35, 40);">] 负责训练循环，允许您在一行代码中微调模型。对于喜欢编写自己训练循环的用户，您也可以在原生 PyTorch 中微调 </font><font style="color:rgb(31, 35, 40);">🤗</font><font style="color:rgb(31, 35, 40);"> Transformers 模型。</font>

<font style="color:rgb(31, 35, 40);">现在，您可能需要重新启动您的</font><code><font style="color:rgb(31, 35, 40);">notebook</font></code><font style="color:rgb(31, 35, 40);">，或执行以下代码以释放一些内存：</font>

```plain
del model
del trainer
torch.cuda.empty_cache()
```

<font style="color:rgb(31, 35, 40);">接下来，手动处理</font><font style="color:rgb(31, 35, 40);"> </font><code><font style="color:rgb(31, 35, 40);">tokenized_dataset</font></code><font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">以准备进行训练。</font>

<font style="color:rgb(31, 35, 40);">移除 text 列，因为模型不接受原始文本作为输入：</font>

1. <font style="color:rgb(31, 35, 40);">>>> tokenized_datasets = tokenized_datasets.remove_columns(\["text"])</font>

<font style="color:rgb(31, 35, 40);">将 label 列重命名为 labels，因为模型期望参数的名称为 labels：</font>

2. <font style="color:rgb(31, 35, 40);">>>> tokenized_datasets = tokenized_datasets.rename_column("label", "labels")</font>

<font style="color:rgb(31, 35, 40);">设置数据集的格式以返回 PyTorch 张量而不是</font><code><font style="color:rgb(31, 35, 40);">lists</font></code><font style="color:rgb(31, 35, 40);">：</font>

3. <font style="color:rgb(31, 35, 40);">>>> tokenized_datasets.set_format("torch")</font>

<font style="color:rgb(31, 35, 40);">接着，创建一个先前展示的数据集的较小子集，以加速微调过程</font>

```plain
>>> small_train_dataset = tokenized_datasets["train"].shuffle(seed=42).select(range(1000))
>>> small_eval_dataset = tokenized_datasets["test"].shuffle(seed=42).select(range(1000))
```

### <font style="color:rgb(31, 35, 40);">DataLoader</font>

<font style="color:rgb(31, 35, 40);">您的训练和测试数据集创建一个</font><code><font style="color:rgb(31, 35, 40);">DataLoader</font></code><font style="color:rgb(31, 35, 40);">类，以便可以迭代处理数据批次</font>

```plain
>>> from torch.utils.data import DataLoader

>>> train_dataloader = DataLoader(small_train_dataset, shuffle=True, batch_size=8)
>>> eval_dataloader = DataLoader(small_eval_dataset, batch_size=8)
```

<font style="color:rgb(31, 35, 40);">加载您的模型，并指定期望的标签数量：</font>

```plain
>>> from transformers import AutoModelForSequenceClassification

>>> model = AutoModelForSequenceClassification.from_pretrained("google-bert/bert-base-cased", num_labels=5)
```

### <font style="color:rgb(31, 35, 40);">Optimizer and learning rate scheduler</font>

<font style="color:rgb(31, 35, 40);">创建一个</font><code><font style="color:rgb(31, 35, 40);">optimizer</font></code><font style="color:rgb(31, 35, 40);">和</font><code><font style="color:rgb(31, 35, 40);">learning rate scheduler</font></code><font style="color:rgb(31, 35, 40);">以进行模型微调。让我们使用 PyTorch 中的</font><font style="color:rgb(31, 35, 40);"> </font>[AdamW](https://pytorch.org/docs/stable/generated/torch.optim.AdamW.html)<font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">优化器：</font>

```plain
>>> from torch.optim import AdamW

>>> optimizer = AdamW(model.parameters(), lr=5e-5)
```

<font style="color:rgb(31, 35, 40);">创建来自 \[</font><code><font style="color:rgb(31, 35, 40);">Trainer</font></code><font style="color:rgb(31, 35, 40);">] 的默认</font><code><font style="color:rgb(31, 35, 40);">learning rate scheduler</font></code><font style="color:rgb(31, 35, 40);">：</font>

```plain
>>> from transformers import get_scheduler

>>> num_epochs = 3
>>> num_training_steps = num_epochs * len(train_dataloader)
>>> lr_scheduler = get_scheduler(
...     name="linear", optimizer=optimizer, num_warmup_steps=0, num_training_steps=num_training_steps
... )
```

<font style="color:rgb(31, 35, 40);">最后，指定</font><font style="color:rgb(31, 35, 40);"> </font><code><font style="color:rgb(31, 35, 40);">device</font></code><font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">以使用 GPU（如果有的话）。否则，使用 CPU 进行训练可能需要几个小时，而不是几分钟。</font>

```plain
>>> import torch

>>> device = torch.device("cuda") if torch.cuda.is_available() else torch.device("cpu")
>>> model.to(device)
```

<font style="color:rgb(31, 35, 40);">如果没有 GPU，可以通过notebook平台如</font><font style="color:rgb(31, 35, 40);"> </font>[Colaboratory](https://colab.research.google.com/)<font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">或</font><font style="color:rgb(31, 35, 40);"> </font>[SageMaker StudioLab](https://studiolab.sagemaker.aws/)<font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">来免费获得云端GPU使用。</font>

<font style="color:rgb(31, 35, 40);">现在您已经准备好训练了！</font><font style="color:rgb(31, 35, 40);">🥳</font>

### <font style="color:rgb(31, 35, 40);">训练循环</font>

<font style="color:rgb(31, 35, 40);">为了跟踪训练进度，使用</font><font style="color:rgb(31, 35, 40);"> </font>[tqdm](https://tqdm.github.io/)<font style="color:rgb(31, 35, 40);"> </font><font style="color:rgb(31, 35, 40);">库来添加一个进度条，显示训练步数的进展：</font>

```plain
>>> from tqdm.auto import tqdm

>>> progress_bar = tqdm(range(num_training_steps))

>>> model.train()
>>> for epoch in range(num_epochs):
...     for batch in train_dataloader:
...         batch = {k: v.to(device) for k, v in batch.items()}
...         outputs = model(**batch)
...         loss = outputs.loss
...         loss.backward()

...         optimizer.step()
...         lr_scheduler.step()
...         optimizer.zero_grad()
...         progress_bar.update(1)
```

### <font style="color:rgb(31, 35, 40);">评估</font>

<font style="color:rgb(31, 35, 40);">就像您在 \[</font><code><font style="color:rgb(31, 35, 40);">Trainer</font></code><font style="color:rgb(31, 35, 40);">] 中添加了一个评估函数一样，当您编写自己的训练循环时，您需要做同样的事情。但与在每个</font><code><font style="color:rgb(31, 35, 40);">epoch</font></code><font style="color:rgb(31, 35, 40);">结束时计算和展示指标不同，这一次您将使用 \[</font><code><font style="color:rgb(31, 35, 40);">~evaluate.add_batch</font></code><font style="color:rgb(31, 35, 40);">] 累积所有批次，并在最后计算指标。</font>

```plain
>>> import evaluate

>>> metric = evaluate.load("accuracy")
>>> model.eval()
>>> for batch in eval_dataloader:
...     batch = {k: v.to(device) for k, v in batch.items()}
...     with torch.no_grad():
...         outputs = model(**batch)

...     logits = outputs.logits
...     predictions = torch.argmax(logits, dim=-1)
...     metric.add_batch(predictions=predictions, references=batch["labels"])

>>> metric.compute()
```
