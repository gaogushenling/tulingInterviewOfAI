## <font style="color:rgb(51, 51, 51);">MCP核心架构与设计理念剖析</font>
### <font style="color:rgb(51, 51, 51);">理论知识</font>
<font style="color:rgb(51, 51, 51);">Model Context Protocol (MCP) 是一个开源标准协议，由 Anthropic 于2024年发布，旨在为AI助手与外部数据源和工具之间建立统一的连接标准。MCP的核心设计理念包括：</font>

**<font style="color:rgb(51, 51, 51);">统一标准化接口</font>**<font style="color:rgb(51, 51, 51);">：MCP提供了一个通用协议来替代碎片化的集成方式，使AI应用能够通过标准化接口访问各种外部资源、工具和提示模板。</font>

**<font style="color:rgb(51, 51, 51);">客户端-主机-服务器架构</font>**<font style="color:rgb(51, 51, 51);">：</font>

+ **<font style="color:rgb(51, 51, 51);">客户端（Client）</font>**<font style="color:rgb(51, 51, 51);">：AI应用或工具，如Claude Desktop、Cursor等</font>
+ **<font style="color:rgb(51, 51, 51);">主机（Host）</font>**<font style="color:rgb(51, 51, 51);">：运行客户端的环境，可以管理多个客户端实例 </font>
+ **<font style="color:rgb(51, 51, 51);">服务器（Server）</font>**<font style="color:rgb(51, 51, 51);">：提供具体功能的后端服务，如数据库访问、文件系统操作等</font>

**<font style="color:rgb(51, 51, 51);">基于能力的协商机制</font>**<font style="color:rgb(51, 51, 51);">：客户端和服务器在初始化时明确声明支持的功能特性，通过能力协商确定会话期间可用的协议功能。</font>

**<font style="color:rgb(51, 51, 51);">安全性优先</font>**<font style="color:rgb(51, 51, 51);">：2025年6月的规范更新引入了资源指示器和增强的授权处理机制，防止恶意服务器获取访问令牌。</font>

### <font style="color:rgb(51, 51, 51);">最佳实践</font>
1. **<font style="color:rgb(51, 51, 51);">安全性设计</font>**<font style="color:rgb(51, 51, 51);">：始终实施强大的同意和授权流程，提供清晰的安全影响文档</font>
2. **<font style="color:rgb(51, 51, 51);">模块化设计</font>**<font style="color:rgb(51, 51, 51);">：采用松耦合的架构，便于维护和扩展</font>
3. **<font style="color:rgb(51, 51, 51);">错误处理</font>**<font style="color:rgb(51, 51, 51);">：实现完善的错误处理和回退机制</font>
4. **<font style="color:rgb(51, 51, 51);">性能优化</font>**<font style="color:rgb(51, 51, 51);">：合理使用缓存和连接池来提升性能</font>

```plain
"""
MCP基础概念演示
"""
from mcp import ClientSession, StdioServerTransport
import asyncio

class MCPBasicExample:
    def __init__(self):
        self.session = None
        
    async def initialize_connection(self, command: list[str]):
        """初始化MCP连接"""
        # 创建STDIO传输
        transport = StdioServerTransport(command)
        
        # 建立客户端会话
        self.session = ClientSession(transport)
        
        # 初始化连接
        await self.session.initialize()
        
        print("MCP连接初始化完成")
        
    async def get_server_capabilities(self):
        """获取服务器能力"""
        if not self.session:
            raise Exception("会话未初始化")
            
        capabilities = self.session.server_capabilities
        print(f"服务器能力: {capabilities}")
        return capabilities
        
    async def list_resources(self):
        """列出可用资源"""
        if not self.session:
            raise Exception("会话未初始化")
            
        resources = await self.session.list_resources()
        print(f"可用资源: {resources}")
        return resources

# 使用示例
async def main():
    example = MCPBasicExample()
    await example.initialize_connection(["python", "simple_server.py"])
    await example.get_server_capabilities()
    await example.list_resources()

if __name__ == "__main__":
    asyncio.run(main())
```

**<font style="color:rgb(51, 51, 51);">上下文管理机制</font>**<font style="color:rgb(51, 51, 51);">：</font>

+ **<font style="color:rgb(51, 51, 51);">会话上下文</font>**<font style="color:rgb(51, 51, 51);">：维护单次对话的状态信息</font>
+ **<font style="color:rgb(51, 51, 51);">资源上下文</font>**<font style="color:rgb(51, 51, 51);">：管理外部数据源的访问状态 </font>
+ **<font style="color:rgb(51, 51, 51);">工具上下文</font>**<font style="color:rgb(51, 51, 51);">：跟踪工具调用的执行状态</font>

**<font style="color:rgb(51, 51, 51);">上下文同步策略</font>**<font style="color:rgb(51, 51, 51);">：</font>

+ **<font style="color:rgb(51, 51, 51);">实时同步</font>**<font style="color:rgb(51, 51, 51);">：关键状态变更立即同步</font>
+ **<font style="color:rgb(51, 51, 51);">批量同步</font>**<font style="color:rgb(51, 51, 51);">：非关键信息批量更新</font>
+ **<font style="color:rgb(51, 51, 51);">延迟同步</font>**<font style="color:rgb(51, 51, 51);">：后台异步处理大量数据</font>

### <font style="color:rgb(51, 51, 51);">Python示例代码</font>
```plain
"""
多上下文管理系统
"""
import asyncio
import json
import time
from typing import Dict, Any, Optional
from dataclasses import dataclass
from collections import defaultdict

@dataclass
class ContextInfo:
    context_id: str
    created_at: float
    last_accessed: float
    data: Dict[str, Any]
    session_id: str

class MultiContextManager:
    def __init__(self, max_contexts: int = 1000):
        self.contexts: Dict[str, ContextInfo] = {}
        self.session_contexts: Dict[str, list[str]] = defaultdict(list)
        self.max_contexts = max_contexts
        
    async def create_context(self, session_id: str, context_data: Dict[str, Any]) -> str:
        """创建新的上下文"""
        context_id = f"{session_id}_{int(time.time() * 1000)}"
        
        # 检查上下文数量限制
        if len(self.contexts) >= self.max_contexts:
            await self._cleanup_old_contexts()
            
        context_info = ContextInfo(
            context_id=context_id,
            created_at=time.time(),
            last_accessed=time.time(),
            data=context_data.copy(),
            session_id=session_id
        )
        
        self.contexts[context_id] = context_info
        self.session_contexts[session_id].append(context_id)
        
        print(f"创建上下文: {context_id}")
        return context_id
        
    async def get_context(self, context_id: str) -> Optional[Dict[str, Any]]:
        """获取上下文数据"""
        if context_id not in self.contexts:
            return None
            
        context_info = self.contexts[context_id]
        context_info.last_accessed = time.time()
        return context_info.data.copy()
        
    async def update_context(self, context_id: str, updates: Dict[str, Any]):
        """更新上下文数据"""
        if context_id not in self.contexts:
            raise ValueError(f"上下文不存在: {context_id}")
            
        context_info = self.contexts[context_id]
        context_info.data.update(updates)
        context_info.last_accessed = time.time()
        
        print(f"更新上下文: {context_id}")
        
    async def merge_contexts(self, target_context_id: str, source_context_id: str):
        """合并两个上下文"""
        target_context = self.contexts.get(target_context_id)
        source_context = self.contexts.get(source_context_id)
        
        if not target_context or not source_context:
            raise ValueError("目标或源上下文不存在")
            
        # 合并数据
        merged_data = {**target_context.data, **source_context.data}
        target_context.data = merged_data
        target_context.last_accessed = time.time()
        
        # 删除源上下文
        await self.delete_context(source_context_id)
        
        print(f"合并上下文: {source_context_id} -> {target_context_id}")
        
    async def get_session_contexts(self, session_id: str) -> list[str]:
        """获取会话的所有上下文"""
        return self.session_contexts.get(session_id, [])
        
    async def delete_context(self, context_id: str):
        """删除上下文"""
        if context_id not in self.contexts:
            return
            
        context_info = self.contexts[context_id]
        session_id = context_info.session_id
        
        # 从会话上下文列表中移除
        if session_id in self.session_contexts:
            self.session_contexts[session_id].remove(context_id)
            
        # 删除上下文
        del self.contexts[context_id]
        
        print(f"删除上下文: {context_id}")
        
    async def _cleanup_old_contexts(self):
        """清理旧的上下文"""
        current_time = time.time()
        timeout = 3600  # 1小时超时
        
        contexts_to_delete = [
            context_id for context_id, context_info in self.contexts.items()
            if current_time - context_info.last_accessed > timeout
        ]
        
        for context_id in contexts_to_delete:
            await self.delete_context(context_id)
            
        print(f"清理了 {len(contexts_to_delete)} 个过期上下文")

# 使用示例
async def demo_multi_context():
    manager = MultiContextManager()
    
    # 创建会话上下文
    session_id = "session_123"
    context_id1 = await manager.create_context(session_id, {
        "user_id": "user_456",
        "conversation_history": ["Hello", "How can I help you?"]
    })
    
    context_id2 = await manager.create_context(session_id, {
        "current_task": "file_analysis",
        "file_path": "/data/report.txt"
    })
    
    # 获取上下文
    context_data = await manager.get_context(context_id1)
    print(f"上下文数据: {context_data}")
    
    # 更新上下文
    await manager.update_context(context_id1, {
        "conversation_history": ["Hello", "How can I help you?", "I need help with data analysis"]
    })
    
    # 合并上下文
    await manager.merge_contexts(context_id1, context_id2)
    
    # 获取会话的所有上下文
    session_contexts = await manager.get_session_contexts(session_id)
    print(f"会话上下文: {session_contexts}")

if __name__ == "__main__":
    asyncio.run(demo_multi_context())
```

### <font style="color:rgb(51, 51, 51);">Python示例代码</font>
```plain
"""
单上下文vs多上下文对比实现
"""
import asyncio
import time
from abc import ABC, abstractmethod
from typing import Dict, Any, List, Optional
from dataclasses import dataclass

@dataclass
class Message:
    content: str
    timestamp: float
    user_id: str
    message_type: str = "user"

class ContextHandler(ABC):
    @abstractmethod
    async def process_message(self, message: Message) -> str:
        pass
    
    @abstractmethod
    async def get_context_info(self) -> Dict[str, Any]:
        pass

class SingleContextHandler(ContextHandler):
    """单上下文处理器"""
    
    def __init__(self):
        self.current_message: Optional[Message] = None
        
    async def process_message(self, message: Message) -> str:
        """处理单条消息，不保留历史"""
        self.current_message = message
        
        # 简单的响应逻辑
        if "hello" in message.content.lower():
            response = "Hello! How can I help you today?"
        elif "help" in message.content.lower():
            response = "I'm here to assist you with your questions."
        else:
            response = f"I understand you said: {message.content}"
            
        return response
        
    async def get_context_info(self) -> Dict[str, Any]:
        """获取当前上下文信息"""
        return {
            "type": "single_context",
            "current_message": self.current_message.content if self.current_message else None,
            "memory_usage": "low"
        }

class MultiContextHandler(ContextHandler):
    """多上下文处理器"""
    
    def __init__(self):
        self.conversation_history: List[Message] = []
        self.user_profiles: Dict[str, Dict[str, Any]] = {}
        self.session_data: Dict[str, Any] = {}
        
    async def process_message(self, message: Message) -> str:
        """处理消息，保持完整上下文"""
        # 添加到历史记录
        self.conversation_history.append(message)
        
        # 更新用户档案
        await self._update_user_profile(message)
        
        # 基于历史上下文生成响应
        response = await self._generate_contextual_response(message)
        
        # 添加响应到历史记录
        response_message = Message(
            content=response,
            timestamp=time.time(),
            user_id="assistant",
            message_type="assistant"
        )
        self.conversation_history.append(response_message)
        
        return response
        
    async def _update_user_profile(self, message: Message):
        """更新用户档案"""
        user_id = message.user_id
        if user_id not in self.user_profiles:
            self.user_profiles[user_id] = {
                "first_seen": message.timestamp,
                "message_count": 0,
                "topics": set()
            }
            
        profile = self.user_profiles[user_id]
        profile["message_count"] += 1
        profile["last_seen"] = message.timestamp
        
        # 简单的主题提取
        if "data" in message.content.lower():
            profile["topics"].add("data_analysis")
        if "help" in message.content.lower():
            profile["topics"].add("help_seeking")
            
    async def _generate_contextual_response(self, message: Message) -> str:
        """基于上下文生成响应"""
        user_profile = self.user_profiles.get(message.user_id, {})
        
        # 检查是否是回头客
        if user_profile.get("message_count", 0) > 1:
            greeting = f"Welcome back! We've chatted {user_profile['message_count']} times."
        else:
            greeting = "Nice to meet you!"
            
        # 基于历史对话生成响应
        recent_messages = self.conversation_history[-5:]  # 最近5条消息
        context_info = f"Based on our conversation history of {len(recent_messages)} recent messages..."
        
        if "hello" in message.content.lower():
            return f"{greeting} How can I help you today?"
        elif "what did we discuss" in message.content.lower():
            topics = list(user_profile.get("topics", set()))
            return f"We've discussed topics like: {', '.join(topics)}"
        else:
            return f"{context_info} I understand: {message.content}"
            
    async def get_context_info(self) -> Dict[str, Any]:
        """获取多上下文信息"""
        return {
            "type": "multi_context",
            "conversation_length": len(self.conversation_history),
            "active_users": len(self.user_profiles),
            "memory_usage": "high",
            "context_details": {
                "total_messages": len(self.conversation_history),
                "unique_users": list(self.user_profiles.keys())
            }
        }

class ContextComparator:
    """上下文模式对比工具"""
    
    def __init__(self):
        self.single_handler = SingleContextHandler()
        self.multi_handler = MultiContextHandler()
        
    async def compare_performance(self, messages: List[Message]):
        """对比两种模式的性能"""
        print("=== 性能对比测试 ===\n")
        
        # 测试单上下文模式
        print("1. 单上下文模式测试:")
        start_time = time.time()
        
        for message in messages:
            response = await self.single_handler.process_message(message)
            print(f"用户: {message.content}")
            print(f"助手: {response}\n")
            
        single_time = time.time() - start_time
        single_info = await self.single_handler.get_context_info()
        
        print(f"单上下文模式耗时: {single_time:.4f}秒")
        print(f"上下文信息: {single_info}\n")
        
        # 测试多上下文模式
        print("2. 多上下文模式测试:")
        start_time = time.time()
        
        for message in messages:
            response = await self.multi_handler.process_message(message)
            print(f"用户: {message.content}")
            print(f"助手: {response}\n")
            
        multi_time = time.time() - start_time
        multi_info = await self.multi_handler.get_context_info()
        
        print(f"多上下文模式耗时: {multi_time:.4f}秒")
        print(f"上下文信息: {multi_info}\n")
        
        # 性能对比结果
        print("=== 对比结果 ===")
        print(f"性能差异: {((multi_time - single_time) / single_time * 100):.2f}%")
        print(f"功能丰富度: 多上下文模式显著优于单上下文模式")

# 使用示例
async def demo_context_comparison():
    comparator = ContextComparator()
    
    # 构造测试消息
    test_messages = [
        Message("Hello", time.time(), "user_1"),
```

```plain
        """处理连续对话"""
        # 初始化用户对话历史
        if user_id not in self.conversations:
            self.conversations[user_id] = []
            
        # 添加用户消息到历史
        self.conversations[user_id].append({
            "role": "user",
            "content": message,
            "timestamp": time.time()
        })
        
        # 基于对话历史生成响应
        response = await self._generate_contextual_response(user_id, message)
        
        # 添加助手响应到历史
        self.conversations[user_id].append({
            "role": "assistant", 
            "content": response,
            "timestamp": time.time()
        })
        
        return response
        
    async def _generate_contextual_response(self, user_id: str, message: str) -> str:
        """基于上下文生成响应"""
        conversation = self.conversations.get(user_id, [])
        
        # 分析对话历史
        if len(conversation) == 1:  # 首次对话
            return f"Hello! Nice to meet you. You said: {message}"
        
        # 查找相关历史对话
        recent_topics = self._extract_topics_from_history(conversation[-5:])
        
        if "continue" in message.lower() or "before" in message.lower():
            return f"Based on our previous discussion about {', '.join(recent_topics)}, let me continue..."
        
        return f"Continuing our conversation (we've discussed {', '.join(recent_topics)}): {message}"
        
    def _extract_topics_from_history(self, messages: List[Dict[str, Any]]) -> List[str]:
        """从历史消息中提取主题"""
        topics = set()
        for msg in messages:
            content = msg.get("content", "").lower()
            if "data" in content:
                topics.add("data analysis")
            if "task" in content:
                topics.add("task management")
            if "file" in content:
                topics.add("file processing")
        return list(topics)

        }
        
        print(f"共享上下文已更新: {key} = {value}")
```

```plain
"""
模块化MCP架构实现
"""
import asyncio
import json
import abc
from typing import Dict, Any, List, Optional, Callable, Type
from dataclasses import dataclass
import importlib
import logging
from pathlib import Path

# =================== 核心接口定义 ===================

class MCPModule(abc.ABC):
    """MCP模块基类"""
    
    @property
    @abc.abstractmethod
    def module_name(self) -> str:
        """模块名称"""
        pass
    
    @property
    @abc.abstractmethod
    def version(self) -> str:
        """模块版本"""
        pass
    
    @abc.abstractmethod
    async def initialize(self, config: Dict[str, Any]) -> bool:
        """初始化模块"""
        pass
    
    @abc.abstractmethod
    async def cleanup(self):
        """清理模块资源"""
        pass
    
    @abc.abstractmethod
    async def health_check(self) -> bool:
        """健康检查"""
        pass

class TransportModule(MCPModule):
    """传输模块接口"""
    
    @abc.abstractmethod
    async def send_message(self, message: Dict[str, Any]) -> bool:
        """发送消息"""
        pass
    
    @abc.abstractmethod
    async def receive_message(self) -> Optional[Dict[str, Any]]:
        """接收消息"""
        pass
    
    @abc.abstractmethod
    async def connect(self) -> bool:
        """建立连接"""
        pass
    
    @abc.abstractmethod
    async def disconnect(self):
        """断开连接"""
        pass

class ProtocolModule(MCPModule):
    """协议模块接口"""
    
    @abc.abstractmethod
    async def process_request(self, request: Dict[str, Any]) -> Dict[str, Any]:
        """处理请求"""
        pass
    
    @abc.abstractmethod
    async def validate_message(self, message: Dict[str, Any]) -> bool:
        """验证消息格式"""
        pass

class BusinessModule(MCPModule):
    """业务模块接口"""
    
    @abc.abstractmethod
    async def handle_resource_request(self, resource_uri: str) -> Any:
        """处理资源请求"""
        pass
    
    @abc.abstractmethod
    async def handle_tool_call(self, tool_name: str, arguments: Dict[str, Any]) -> Any:
        """处理工具调用"""
        pass

class StdioTransportModule(TransportModule):
    """STDIO传输模块"""
    
    def __init__(self):
        self.connected = False
        self.process = None
        
    @property
    def module_name(self) -> str:
        return "stdio_transport"
    
    @property
    def version(self) -> str:
        return "1.0.0"
    
    async def initialize(self, config: Dict[str, Any]) -> bool:
        """初始化STDIO传输"""
        self.command = config.get("command", [])
        logging.info(f"初始化STDIO传输: {self.command}")
        return True
    
    async def connect(self) -> bool:
        """建立STDIO连接"""
        try:
            # 这里应该启动子进程
            self.connected = True
            logging.info("STDIO连接已建立")
            return True
        except Exception as e:
            logging.error(f"STDIO连接失败: {e}")
            return False
    
    async def send_message(self, message: Dict[str, Any]) -> bool:
        """发送消息到STDIO"""
        if not self.connected:
            return False
        
        try:
            message_json = json.dumps(message)
            logging.debug(f"发送STDIO消息: {message_json}")
            return True
        except Exception as e:
            logging.error(f"发送STDIO消息失败: {e}")
            return False
    
    async def receive_message(self) -> Optional[Dict[str, Any]]:
        """从STDIO接收消息"""
        if not self.connected:
            return None
        
        # 模拟接收消息
        return {"jsonrpc": "2.0", "method": "ping", "id": 1}
    
    async def disconnect(self):
        """断开STDIO连接"""
        self.connected = False
        logging.info("STDIO连接已断开")
    
    async def cleanup(self):
        """清理资源"""
        await self.disconnect()
    
    async def health_check(self) -> bool:
        """健康检查"""

class JsonRpcProtocolModule(ProtocolModule):
    """JSON-RPC协议模块"""
    
    def __init__(self):
        self.request_id = 0
        
    @property
    def module_name(self) -> str:
        return "jsonrpc_protocol"
    
    @property
    def version(self) -> str:
        return "2.0.0"
    
    async def initialize(self, config: Dict[str, Any]) -> bool:
        """初始化协议模块"""
        self.timeout = config.get("timeout", 30)
        logging.info("JSON-RPC协议模块已初始化")
        return True
    
    async def validate_message(self, message: Dict[str, Any]) -> bool:
        """验证JSON-RPC消息格式"""
        required_fields = ["jsonrpc"]
        
        for field in required_fields:
            if field not in message:
                return False
        
        if message["jsonrpc"] != "2.0":
            return False
            
        # 检查是否是请求或响应
        is_request = "method" in message
        is_response = "result" in message or "error" in message
        
        return is_request or is_response
    
    async def process_request(self, request: Dict[str, Any]) -> Dict[str, Any]:
        """处理JSON-RPC请求"""
        if not await self.validate_message(request):
            return self._create_error_response(
                request.get("id"), -32600, "Invalid Request"
            )
        
        method = request.get("method")
        params = request.get("params", {})
        request_id = request.get("id")
        
        logging.info(f"处理JSON-RPC请求: {method}")
        
        # 这里应该路由到具体的处理器
        result = {"status": "success", "method": method}
        
        return {
            "jsonrpc": "2.0",
            "result": result,
            "id": request_id
        }
    
    def _create_error_response(self, request_id: Any, code: int, message: str) -> Dict[str, Any]:
        """创建错误响应"""
        return {
            "jsonrpc": "2.0",
            "error": {"code": code, "message": message},
            "id": request_id
        }
    
    async def cleanup(self):
        """清理资源"""
        pass
    
    async def health_check(self) -> bool:
        """健康检查"""
        return True

class FileSystemBusinessModule(BusinessModule):
    """文件系统业务模块"""
    
    def __init__(self):
        self.base_path = None
        
    @property
    def module_name(self) -> str:
        return "filesystem_business"
    
    @property
    def version(self) -> str:
        return "1.0.0"
    
    async def initialize(self, config: Dict[str, Any]) -> bool:
        """初始化文件系统模块"""
        self.base_path = Path(config.get("base_path", "."))
        self.allowed_extensions = config.get("allowed_extensions", [".txt", ".json", ".py"])
        logging.info(f"文件系统模块初始化: {self.base_path}")
        return True
    
    async def handle_resource_request(self, resource_uri: str) -> Any:
        """处理文件资源请求"""
        try:
            if resource_uri.startswith("file://"):
                file_path = Path(resource_uri[7:])  # 移除 file:// 前缀
                
                # 安全检查
                if not self._is_safe_path(file_path):
                    raise ValueError("不安全的文件路径")
                
                full_path = self.base_path / file_path
                
                if full_path.exists() and full_path.is_file():
                    content = full_path.read_text(encoding="utf-8")
                    return {
                        "uri": resource_uri,
                        "content": content,
                        "mimeType": "text/plain"
                    }
                else:
                    raise FileNotFoundError(f"文件不存在: {full_path}")
                    
        except Exception as e:
            logging.error(f"处理资源请求失败: {e}")
            raise
    
    async def handle_tool_call(self, tool_name: str, arguments: Dict[str, Any]) -> Any:
        """处理工具调用"""
        if tool_name == "list_files":
            return await self._list_files(arguments.get("directory", "."))
        elif tool_name == "read_file":
            return await self._read_file(arguments.get("path"))
        elif tool_name == "write_file":
            return await self._write_file(arguments.get("path"), arguments.get("content"))
        else:
            raise ValueError(f"未知工具: {tool_name}")
    
    async def _list_files(self, directory: str) -> List[Dict[str, Any]]:
        """列出文件"""
        dir_path = self.base_path / directory
        
        if not self._is_safe_path(Path(directory)):
            raise ValueError("不安全的目录路径")
        
        files = []
        for item in dir_path.iterdir():
            if item.is_file() and item.suffix in self.allowed_extensions:
                files.append({
                    "name": item.name,
                    "path": str(item.relative_to(self.base_path)),
                    "size": item.stat().st_size,
                    "type": "file"
                })
            elif item.is_dir():
                files.append({
                    "name": item.name,
                    "path": str(item.relative_to(self.base_path)),
                    "type": "directory"
                })
        
        return files
    
    async def _read_file(self, path: str) -> str:
        """读取文件"""
        file_path = Path(path)
        
        if not self._is_safe_path(file_path):
            raise ValueError("不安全的文件路径")
        
        full_path = self.base_path / file_path
        return full_path.read_text(encoding="utf-8")
    
    async def _write_file(self, path: str, content: str) -> bool:
        """写入文件"""
        file_path = Path(path)
        
        if not self._is_safe_path(file_path):
            raise ValueError("不安全的文件路径")
        
        full_path = self.base_path / file_path
        full_path.parent.mkdir(parents=True, exist_ok=True)
        full_path.write_text(content, encoding="utf-8")
        return True
    
    def _is_safe_path(self, path: Path) -> bool:
        """检查路径安全性"""
        # 防止目录遍历攻击
        try:
            resolved_path = (self.base_path / path).resolve()
            return str(resolved_path).startswith(str(self.base_path.resolve()))
        except:
            return False
    
    async def cleanup(self):
        """清理资源"""
        pass
    
    async def health_check(self) -> bool:
        """健康检查"""
        return self.base_path.exists() if self.base_path else False

@dataclass
class ModuleConfig:
    module_class: Type[MCPModule]
    config: Dict[str, Any]
    enabled: bool = True
    dependencies: List[str] = None

class ModularMCPServer:
    """模块化MCP服务器"""
    
    def __init__(self):
        self.modules: Dict[str, MCPModule] = {}
        self.module_configs: Dict[str, ModuleConfig] = {}
        self.initialized = False
        
    def register_module(self, name: str, module_config: ModuleConfig):
        """注册模块"""
        self.module_configs[name] = module_config
        logging.info(f"注册模块: {name}")
    
    async def initialize_all(self):
        """初始化所有模块"""
        # 按依赖顺序初始化
        initialized_modules = set()
        
        while len(initialized_modules) < len(self.module_configs):
            progress_made = False
            
            for name, config in self.module_configs.items():
                if name in initialized_modules or not config.enabled:
                    continue
                
                # 检查依赖是否已初始化
                dependencies = config.dependencies or []
                if all(dep in initialized_modules for dep in dependencies):
                    # 初始化模块
                    module_instance = config.module_class()
                    success = await module_instance.initialize(config.config)
                    
                    if success:
                        self.modules[name] = module_instance
                        initialized_modules.add(name)
                        progress_made = True
                        logging.info(f"模块初始化成功: {name}")
                    else:
                        logging.error(f"模块初始化失败: {name}")
                        
            if not progress_made:
                raise Exception("模块依赖循环或初始化失败")
        
        self.initialized = True
        logging.info("所有模块初始化完成")
    
    async def get_module(self, name: str, module_type: Type = None) -> Optional[MCPModule]:
        """获取模块实例"""
        module = self.modules.get(name)
        
        if module and module_type:
            if isinstance(module, module_type):
                return module
            else:
                return None
        
        return module
    
    async def health_check_all(self) -> Dict[str, bool]:
        """检查所有模块健康状态"""
        results = {}
        
        for name, module in self.modules.items():
            try:
                results[name] = await module.health_check()
            except Exception as e:
                logging.error(f"模块健康检查失败 {name}: {e}")
                results[name] = False
        
        return results
    
    async def cleanup_all(self):
        """清理所有模块"""
        for name, module in self.modules.items():
            try:
                await module.cleanup()
                logging.info(f"模块清理完成: {name}")
            except Exception as e:
                logging.error(f"模块清理失败 {name}: {e}")
        
        self.modules.clear()
        self.initialized = False
```
