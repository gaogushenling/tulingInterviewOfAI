### <font style="color:rgb(36,91,219);">1.2 </font>**解码器****结构：带掩码的Self-Attention层 + Self-Attention 层+一个****前馈神经网络**

![1758769601793-85ecc775-cedc-488f-82c7-8b6178cdb5fd.png](./img/13jqKsRLXmfpUQth/1758769601793-85ecc775-cedc-488f-82c7-8b6178cdb5fd-859543.png)

在解码器中，第一个Self-Attention和编码器的第一个自注意力层也是不同的。它是一个带掩码的自注意力层，带掩码的意思就是，对于一个总共有N个单词的词序列，在翻译到第K个单词时候，这个自注意力层只能注意到第1到第K个单词，而注意不到第K+1到第N个单词。后面我们会用一张图很清晰的展示什么是带掩码。

#### <font style="color:rgb(36,91,219);">2.1.2 </font>**Positional Encoding，PE**
Transformer中的编码器不只采用了词嵌入本身的Embedding，还为每个词基于位置额外增加了一个Embedding（Positional Encoding），它的维度和词嵌入是一样的。最终输入给Transformer的是两个嵌入向量的和。

这是因为Transformer激进地放弃了自带时序处理能力的RNN，而Attention本身又是不会有时序信息的（<font style="background-color:rgba(254,212,164,0.8);">用自注意力实现全局，不等于拥有时序信息！全局不等于时序</font>）。

| <font style="color:rgb(143,149,158);">Transformer 不采用 </font><font style="color:rgb(143,149,158);">RNN</font><font style="color:rgb(143,149,158);"> 的结构，使用全局信息，不能利用单词的顺序信息，而顺序信息对于 </font><font style="color:rgb(143,149,158);">NLP</font><font style="color:rgb(143,149,158);"> 来说又非常重要。所以 Transformer 中使用位置 Embedding 保存单词在序列中的相对或绝对位置。</font> |
| :--- |


通过Positional Encoding，<font style="color:rgb(143,149,158);">模型可以确定每个单词的位置或不同单词之间的距离。</font>

![1758769602449-7cc2ea56-db19-4bd9-b49e-8ef3fc22c02d.png](./img/13jqKsRLXmfpUQth/1758769602449-7cc2ea56-db19-4bd9-b49e-8ef3fc22c02d-992750.png)

位置编码需要做到：每个位置对应的编码唯一；不论句子有多长，每两个相邻位置之间的距离都一样；所有的编码都要在一个有限的区间内，编码用到的数字不能爆炸上升（这其实真的很难做到！）。

| <font style="color:rgb(143,149,158);">具体的，Transformer里的位置编码是这样做的：</font><br/>![1758769602783-7ae62c4c-4d11-4a4c-8ade-79b62a0339f9.png](./img/13jqKsRLXmfpUQth/1758769602783-7ae62c4c-4d11-4a4c-8ade-79b62a0339f9-089292.png)<br/><font style="color:rgb(143,149,158);">它是一个和词嵌入同维的、sin和cos交替的向量。</font> |

### <font style="color:rgb(36,91,219);">2.2 </font>**Self-Attention层：细说自注意力机制**
<font style="background-color:rgba(251,191,188,0.8);">7.3.3里，我们提到过</font><font style="background-color:rgba(251,191,188,0.8);">注意力机制</font><font style="background-color:rgba(251,191,188,0.8);">的作用。</font>这里我们再提一次。

| <font style="color:rgb(143,149,158);">Say the following sentence is an input sentence we want to translate:</font><br/><font style="color:rgb(143,149,158);">”</font><font style="color:rgb(143,149,158);background-color:rgba(222,224,227,0.8);">The animal didn't cross the street because it was too tired</font><font style="color:rgb(143,149,158);">”</font><br/><font style="color:rgb(143,149,158);">What does “it” in this sentence refer to? Is it referring to the street or to the animal? It’s a simple question to a human, but not as simple to an algorithm.</font><br/><font style="color:rgb(143,149,158);">When the model is processing the word “it”, self-attention allows it to associate “it” with “animal”.</font><br/><font style="color:rgb(143,149,158);">As the model processes each word (each position in the input sequence), self attention allows it to look at other positions in the input sequence for clues that can help lead to a better encoding for this word.</font><br/><font style="color:rgb(143,149,158);">If you’re familiar with RNNs, think of how maintaining a hidden state allows an RNN to incorporate its representation of previous words/vectors it has processed with the current one it’s processing. Self-attention is the method the Transformer uses to bake the “understanding” of other relevant words into the one we’re currently processing.</font> |

### <font style="color:rgb(36,91,219);">2.3 </font>**图解多头自注意力机制**
2.2里我们讲明白了Self-Attention，那什么是Multi-Head呢？

| <font style="color:rgb(143,149,158);">The paper further refined the self-attention layer by adding a mechanism called “multi-headed” attention. This improves the performance of the attention layer in two ways:</font><br/>1. <font style="color:rgb(143,149,158);background-color:rgba(254,212,164,0.8);">It expands the model’s ability to focus on different positions.</font><font style="color:rgb(143,149,158);"> Yes, in the example above, z1 contains a little bit of every other encoding, but it could be dominated by the actual word itself. If we’re translating a sentence like “The animal didn’t cross the street because it was too tired”, it would be useful to know which word “it” refers to.</font><br/>2. <font style="color:rgb(143,149,158);background-color:rgba(254,212,164,0.8);">It gives the attention layer multiple “</font>**<font style="color:rgb(143,149,158);background-color:rgba(254,212,164,0.8);">representation subspaces</font>**<font style="color:rgb(143,149,158);background-color:rgba(254,212,164,0.8);">”. </font><font style="color:rgb(143,149,158);">As we’ll see next, with multi-headed attention we have not only one, but multiple sets of </font><font style="color:rgb(143,149,158);">Query</font><font style="color:rgb(143,149,158);">/Key/</font><font style="color:rgb(143,149,158);">Value</font><font style="color:rgb(143,149,158);"> weight matrices (the Transformer uses eight attention heads, so we end up with eight sets for each encoder/</font><font style="color:rgb(143,149,158);">decoder</font><font style="color:rgb(143,149,158);">). Each of these sets is randomly initialized. Then, after training, each set is used to project the input embeddings (or vectors from lower encoders/decoders) into a different representation subspace.</font> |
| :--- |

![1758769605646-ddda3e9c-cf32-48a4-b24d-bacf3741346f.png](./img/13jqKsRLXmfpUQth/1758769605646-ddda3e9c-cf32-48a4-b24d-bacf3741346f-559568.png)

<font style="color:rgb(143,149,158);">我们将这些矩阵连接起来，形成了一个2*512维的矩阵；然后将其乘以一个产生最终输出的权重矩阵。</font>

### <font style="color:rgb(36,91,219);">2.4 </font>**总结：自注意力层中发生了什么？**
+ 输入：基于one-hot，假设字典大小是30,000,那么一个词的输入就是一个30K维的向量，对应该词汇的元素会是1，其他的全部都是0。
+ Embedding层：把输入的one-hot向量乘以一个矩阵后，投影到512维的词向量里，再加上一个位置嵌入。
+ 自注意力层：对输入的词嵌入，乘三个权重矩阵，投影出Q，K，V。输入每一个词Qk会和输入的全部词的K1、K2、K3….Kn向量做点积（向量点积得到的是标量），得到一个n维的新向量（n就是输入的句子的长度）。对向量的元素除以8（根号64），再做一个softmax，得到一个Attention Distribution，这个分布反映了当前输入的词对句子中每一个词的相关性。而后我们对V向量以Attention Distribution为权重做一个加权，得到向量Z。向量Z里就蕴含了当前timestep下来自整个句子的各种信息。
+ 多头注意力机制：多训练几个不同的权重矩阵组合，把他们最后得到的结果拼接到一起，提高信息收集维度的数量和鲁棒性。

![1758769605801-94e600b6-0672-47c0-a1f1-9ff32319a866.png](./img/13jqKsRLXmfpUQth/1758769605801-94e600b6-0672-47c0-a1f1-9ff32319a866-776016.png)

自注意力层最终输出的一个N*512的矩阵会输入给前馈神经网络。**嗯，所以它的形状和最开始的时候输入的矩阵是一样的**。<font style="background-color:rgba(183,237,177,0.8);">即：一个多头自注意力层并不改变输入的东西的形状。</font>

<font style="background-color:rgba(251,191,188,0.8);">FFNN就是一个平平无奇的全连接层，和2.1.4中介绍的东西没有什么区别，所以就不再专门做介绍了。</font>

它也不改变输入的东西的形状。总之，输入一个（batchsize, seq_length, embed_dim）的张量到一个Encoder Block里去，输出的也是一个同维的张量。

## <font style="color:rgb(36,91,219);">3. </font>**解码器介绍**
解码器的结构在1.2里展示过，这里不再重复。

与seq2seq一样，Transformer中的解码器本质上也是一个语言模型，它做的事情就是综合考虑当前时间步的信息和Encoder给来的信息，进行一个词一个词的自回归的输出。

<font style="background-color:rgba(251,191,188,0.8);">既然同样是一个自回归语言模型，那么7.2.2提到的Teaching Force和计划采样、7.2.3中提到的Beam Search在Decoder中都是同样适用的</font>。这里也不重复介绍了。

![1758769605829-4e5309dd-9cd3-45e7-9974-4007c89321b6.png](./img/13jqKsRLXmfpUQth/1758769605829-4e5309dd-9cd3-45e7-9974-4007c89321b6-473189.png)

<font style="background-color:rgba(183,237,177,0.8);">Decoder模型中的一些细节可能需要更多的输入才能讲清楚，所以现在我们试图去翻译I have a cat为中文。</font>

### <font style="color:rgb(36,91,219);">3.1 </font>**解码器的第一层：带掩码的多头自注意力层**
解码器中的自注意力层和编码器中的不太一样：在解码器中，自注意力层只允许关注已输出位置的信息。所以我们称之为“带掩码的自注意力层”。

| <font style="color:rgb(143,149,158);">Decoder block 的第一个 Multi-Head Attention 采用了 Masked 操作，因为在翻译的过程中是顺序翻译的，即翻译完第 i 个单词，才可以翻译第 i+1 个单词。通过 Masked 操作可以防止第 i 个单词知道 i+1 个单词之后的信息。</font> |
| :--- |


Mask操作主要是在Softmax的时候实现的。

## <font style="color:rgb(36,91,219);">4 </font>**Transformer模型总结**
### <font style="color:rgb(36,91,219);">4.1 </font>**模型可以去调的超参数**
<font style="background-color:rgba(255,246,122,0.8);">Transformer里可以调的参数其实并不多。</font>

1. 词嵌入的向量有几维；
2. 编码器和解码器各自有多少层。如果没有编码器，那就是Decoder-Only<font style="background-color:rgba(251,191,188,0.8);">（GPT）</font>；如果没有解码器，那就是Encoder-Only<font style="background-color:rgba(251,191,188,0.8);">（BERT）</font>
3. 有多少个注意力头。

### <font style="color:rgb(36,91,219);">4.2 </font>**模型整体的前向传播步骤**
**编码器：**

+ 输入：基于one-hot，假设字典大小是30,000,那么一个词的输入就是一个30K维的向量，对应该词汇的元素会是1，其他的全部都是0；输入一个句子的话，那就是矩阵了。
+ Word Embedding层：把输入的one-hot向量乘以一个矩阵后，投影到512维的词向量里。此外还要考虑位置编码，它是一个和词嵌入同维的、sin和cos交替的向量，两者可以直接相加作为最后的输入。
+ 自注意力层：对输入的词向量，乘三个权重矩阵，投影出Q，K，V。输入的第k个词的查询向量Qk会和输入的全部词的K1、K2、K3….Kn向量做点积（向量点积得到的是标量），得到一个n维的新向量（n就是输入的句子的长度）。除以8，再做一个softmax，得到一个Attention Distribution，这个分布反映了当前输入的词对句子中的每一个词的相关性。而后我们对V向量以Attention Distribution为权重做一个加权，得到向量Z。向量Z里就蕴含了当前timestep下来自整个句子的各种信息。
+ 多头注意力机制：多训练几个不同的自注意力层，最后拼接到一起，提高信息收集维度的数量和鲁棒性。
+ 自注意力层的输出会经过一个全连接层，生成一个向量，而后传给下一个编码器。最后一个编码器输出的向量会与权重矩阵C相乘，生成价值矩阵V和钥匙矩阵K。

**解码器：**

+ 带掩码的多头自注意力层：Decoder的输入里，在自注意力层中，对于当前的time step之后的单词，在softmax之前都会加一个巨大的负数，让他们的attention distribution都会是0。最终输出的张量会作为下一层的查询矩阵。因为是8头注意力，所以最后会输出8个不同的查询矩阵，
+ 编码器-解码器注意力层：这一层中，会用来自编码器的8个K和来自上一层的8个Q做点积操作，计算出注意力分布后再和来自编码器的8个V矩阵做加权。
+ 输出：解码器以自回归的形式一个一个输出，当前的输出成为下一个输入。输出的部分可以greedy，也可以做一个beam search。

<font style="background-color:rgba(251,191,188,0.8);">损失函数和反向传播这里就跳过了。</font><font style="background-color:rgba(255,246,122,0.8);">损失函数依然是交叉熵函数。</font>

### <font style="color:rgb(36,91,219);">4.3 </font>**Transformer的牛逼之处**
+ Transformer 与 RNN 不同，不论是自注意力层还是全连接层都是矩阵运算，可以比较好地并行训练。<font style="color:rgb(143,149,158);background-color:rgba(251,191,188,0.8);">在做NLP的任务时，CNN、RNN和Transformer相比，并行程度CNN大于Transformer远大于RNN，信息糅合能力RNN大于Transformer远大于CNN</font>。<font style="background-color:rgba(255,246,122,0.8);">Transformer它没有被任何人远大于，可能这就是它为什么牛逼吧</font>。
+ Transformer 本身是不能利用单词的顺序信息的，因此需要在输入中添加位置 Embedding，否则 Transformer 就是一个词袋模型了。
+ Transformer 的重点是 Self-Attention 结构，其中用到的 Q, K, V矩阵通过输出进行线性变换得到。<font style="background-color:rgba(222,224,227,0.8);">这件事情还是挺天才的，正经人很难想到自己和自己做点积然后再和另一个自己相乘。</font>
+ Transformer 中 Multi-Head Attention 中有多个 Self-Attention，可以捕获单词之间多种维度上的相关系数。<font style="background-color:rgba(254,212,164,0.8);">八个注意力头在8个不同的表征子空间横扫信息，让模型学习能力非常强</font>。

### <font style="color:rgb(36,91,219);">4.4 </font>**Transformer的评价**
+ 它几乎被用在所有的NLP任务上，产生了类似CNN对CV的改变。
+ 几乎用在了每一个模态的机器学习上，文本、图片、视频，万物皆可Transformer。
+ 想要让Transformer达到和CNN、RNN一样的效果，得给他喂多得多的数据量。基于Transformer的模型都很大、很贵，虽然它在刷SOTA上所向披靡，但是CV业内其实还是CNN用的更多。
+ 事实上，Attention is NOT All You Need（_<font style="color:rgb(216,57,49);background-color:rgba(222,224,227,0.8);">就像The Document is NOT All You Need一样，没有其他的参考文献还是不可能去扎实的掌握LLM的技术原理</font>_）。后续的研究中发现，Transformer中的Resnet和MLP们都起到了很大的作用，缺一不可。如果只训练多头自注意力的话，最后的效果会非常糟糕。

_<font style="background-color:rgba(222,224,227,0.8);"><后续出现了大量的魔改Transformer，有人抛弃了Encoder只留下Decoder，有人则只用了Encoder。但不论怎样，多头自注意力机制这样天才的想法还是被得以保留></font>_
